# SH36735XX 验证记录与限制

验证对象：SH36735XX CV1.0A.pdf（页脚V1.0A）与SH36735XX CV0.2C.pdf（页脚V0.2C、Preliminary），每份57页。PDF页码等于印刷页码。验证日期：2026-10-05。

## 1. 已实际完成的检查

1. 使用pdftotext -layout独立提取两份全部114页；没有只靠搜索片段撰写
2. 两版每页去除空白/系列页眉/Preliminary/封面版本字样，执行规范化比较：26页不同、31页相同。对差异进行跨页复核，区别实质变化与文字移页。结果见 [version_diff_audit.json](version_diff_audit.json) 和 [version_differences.md](version_differences.md)
3. 从两版各自p28–30独立解析90个寄存器地址和8bit标签；对详细表访问/复位/说明进行整理，形成180条按版记录。35条复位行序列由两份p31–44独立提取并比较，完全相同；分组测量/均衡表复位行展开到每个地址
4. 用pdftoppm渲染关键页，使用图像查看工具实际检查下表列出的25张图。渲染本身不等于目视检查，只列已查看页面
5. 检查寄存器字段掩码覆盖、初值重建、按版完整地址范围、引用文件存在、PDF页码范围和遗留占位符
6. 改正排版标记处理造成的两处测试电流引用问题：SDO VOL=0.6V条件是IOL=15mA，RESET/ALARM VOL=0.4V条件是IOL=1mA，不是页15/页1引用；重新扫描同类错误，未发现残留

## 3. 自动结构验证

实际结果见 [validation_results.json](validation_results.json)：

- 180条寄存器记录，180个唯一revision+address
- 每版地址连续0x40–0x99，恰90条
- 每条字段mask不重叠且完整覆盖8位，保留位不丢失
- 每条字段复位值重建结果等于字节复位值
- 所有记录均有匹配revision的源文件、有效页码和相对PDF链接
- 两版原始地址表名字和8位标签逐行相同；两份各35条复位行相同
- 114个唯一revision+page覆盖条目，文件与章节映射均存在
- 所有正文/差异表本地文件链接有效；PDF页码在1..57范围
- 没有待替换模板标记或“引用紧接测试电流单位”的错误

这验证了结构完整性，不等于已在真实芯片上验证所有语义。

## 4. 明确保留的源内冲突与未知项

| 项目 | 处理方式 |
|---|---|
| SPI写CRC包含哪些字节 | 图与正文分别保留；不发布“已验证”的CRC驱动实现或测试向量 |
| CRC反射/最终异或 | 手册未明说，未补造 |
| 电流负码格式 | 明确保存bit15方向；signed_binary_encoding为null，不默认补码/原码 |
| 新版断线掩码 | 标为源内矛盾；未默默交换奇偶掩码 |
| CADCDL bit1 | source_table_bit_labels保留总表CADCD.0；结构化bitfields采用详细表CADCD.1，notes解释选择 |
| CELL6H/CELL16H bit3 | 采用总表的.11，记录详细表重复.12的冲突 |
| FLAG1复位/软件复位 | 保留0x80表值及软件复位不置标志的文字，记录冲突 |
| WDT预放电关闭条件 | 7.9限定与8.2无条件关断都注明，要求台架/厂商确认 |
| OCD2/UV/PDSG时长上限 | 分别保留编码与电气表数值，不“取更大者”改编码 |
| VVCPTH参考点 | 保持源表写法，不自造差分参考 |
| ADC跨字节快照 | 手册未承诺；只给工程层验证建议 |
| 用户EEPROM/校准写接口 | 未公开，JSON为null，未凭E2P_ERR推断主机可写EEPROM |
| PCB布局/EMC/热/安规完整参数 | 手册没有的保持未知，工程建议单独标识 |
| 原理图完整网表 | 仅做关键拓扑/器件变更核验，未自动重建可制造网表；最终设计仍须逐线审图 |

## 5. 可用性结论

本包已经完成两版全文覆盖、重点工程综合、全部公开RAM地址结构化、版本差异与关键图像复核，适合检索、辅助设计审查和制定驱动规格。它不是已在真实AFE上通过的驱动，不替代原始PDF、厂商更正或受限能台架测试。所有没有证据的内容保持未知或明确标为工程建议。
