## 关键不确定性（必须随交付保留）

1. 二次校准公式与速查表不一致；同页 100V 和 120V 反例见 reference.md §4.4。需厂商确认，未自行选择或改系数
2. 数据手册 0x90 寄存器范围与初始 RA 到 0x8F 的文字不一致。0x90 未命名，驱动不要依赖回卷
3. SCDT=0 的公式值与电气规格下限不一致，复位 SCDE 又开启；禁止把门限0当禁用
4. DS IWT 非零说法与 RM 0XX 禁用不一致；只使用明确 100～111 编码
5. RM VTP 名称 VTOP 与 DS C24 对地采样图存在节点差异
6. 放电续流比较方向图文不一致；标志节点在 HSFM 前，不能宣称状态位证明实际高边导通
7. 预驱动 32μA 文本与 36μA 电气典型不同；开关沿表列最小值，不可当最坏关断上限
8. COTT 最低非零温度高于 85°C 额定结温；需要 MCU 自行温控余量
9. 唤醒波形/最大延时、全 CRC 参数/向量、多字节原子快照、完整断线诊断标准、NTC温度曲线、用户非易失配置提交均未明确
10. 复位变化有 RM V1.1/V1.2 历史；本包只按所提供 V1.2 的 CPVS/VAE 默认，不保证任意硬件批次一致

完整出处和处理策略见 reference.md §9.2；不确定处在 JSON reset 或 narrative 中显式保留，不补零。

## 结构化验证

- 地址长度 145、起止 0x00/0x90、无缺口或重复
- 每字节 8 个唯一位；位掩码覆盖 0xFF；已知默认掩码正确组合
- 0x00 全部转换为 R/W0C，原表 R/W 保留；0x01 B6/B5/B4 和 0x76 B7 为 RC；0x55 B0 记录触发自清，不错标 W1C
- 0x52=0x90、0x53=0x59、0x54=0xF9、0x55=0x2C、0x56=0xFF、0x6D=0x28、0x6E=0xCD、0x77=0xC0 与详细表逐位组合相符
- 所有 PDF 来源含准确原文件名、PDF页、印刷页和相对链接；原文件存在，页码范围有效
- 数学核对：COTT(1)=88.14556°C；K(100V)=0.998835；K(120V)=0.998314
- 文件可被 JSON 解析；逐页 coverage 总计 62；reference 无未展开引用占位符
- 独立将 RM p2～5 总表逐字节与 p6～29 详细表交叉核对；仅出现已保留的 0x5C 总表 OCCD 与详细表 OCC1D 命名差异
- 所有已命名 bitfield 均有对应字段语义；COVD、CUVD、TWSE、CST 各保留 16 项编码，GP2M 保留 8 项编码
