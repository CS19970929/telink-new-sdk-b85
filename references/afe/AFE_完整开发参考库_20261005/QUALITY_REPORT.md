## 全文与图表

328 页均有独立的页面索引和原 PDF。324 页存在非空提取文本；BQ76940.pdf 第 59–62 页是无可提取文本的机械图纸页，已在对应参考中单列，并保留原图证据。

正文按开发任务重新组织，覆盖器件范围、引脚、电气约束、通信和 CRC、寄存器、转换与校准、数据更新、保护和恢复、MOS、低功耗、均衡、配置保持及应用/封装。寄存器字段还保留来源表或字段级解释，便于对照。

原件中的连线、机械轮廓、曲线采样点及全部图形元素没有被声称已无损转换成 Markdown 或机器数据。涉及这些内容时，应直接查看相应 PDF。无文字提取的页面也不是“空白页”。

## 已执行的验证

- 对六份原件记录完整 SHA-256、页数、字节数，并检查打包后对应内容
- 检查所有 JSON 可解析及寄存器数据的基础结构 schema；按芯片/版本检查地址重复和位掩码一致性
- 核对逐页 TXT 与 JSONL 文本一致、页面序号连续，并验证局部引用对应真实原文件与有效 PDF 页码
- 检查本地 Markdown 链接、已使用的章节锚点、JSON 中的来源页链接和主要覆盖入口
- 关键电气、寄存器、公式、时序、保护、应用与封装页面采用原图复核；精确页面及结果分别列于下方记录

## 如何复查

在解压后的包根目录执行：

```sh
python3 tools/verify_pack.py
```

该脚本只读本地文件，无网络操作。可选使用标准 JSON Schema 验证器检查 `data/register_dataset.schema.json`；此 schema 刻意只认证结构，数值和语义仍以每组源页为准。
