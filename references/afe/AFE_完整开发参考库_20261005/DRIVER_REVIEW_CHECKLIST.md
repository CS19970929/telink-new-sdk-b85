# AFE 驱动实现与评审核对清单

本清单为工程建议。具体寄存器、数值和时序从精确型号/版本的参考中查取，不是任一器件的统一初始化算法，也不是产品安全认证标准。

## 身份与硬件

- [ ] 已记录芯片完整型号、后缀、版本/订单选项和来源手册 SHA-256
- [ ] 已确认实际串数、未使用采样输入连接、供电参考地与所有引脚电压域
- [ ] 分流器采用实际设计值与单位；方向约定与原始寄存器正负号可追溯
- [ ] NTC、固定电阻及通道接法与公式一致；不支持的传感器与失效传感器分别处理
- [ ] FET 高低边、预充/预放、二极管通路、负载/充电器检测及引脚极性逐一对应

## 传输

- [ ] 明确 7-bit 地址/总线地址字节或 SPI 命令编码；不使用其他 AFE 的封装层假设
- [ ] 逐字节列出一次读/写的帧、字节顺序、ACK/NACK/CS/重复起始、长度和边界
- [ ] CRC 多项式、初值、位顺序、覆盖字节、每包或每字节范围均有本型号证据
- [ ] 短读、超时、CRC 错误、总线错误均不会把旧数据当成功读数
- [ ] 重试不会重复执行具有写/读副作用的操作，部分成功可被检测

## 寄存器与持久化

- [ ] 地址、宽度、访问属性、复位值与位域逐项对应，不把空白默认填零
- [ ] 保留位按手册要求处理；不使用可能破坏 W0C/W1C/读清状态的通用 RMW
- [ ] 配置写入的解锁、校验、CRC、等待、读回、重锁和掉电行为均有适用证据
- [ ] 暂存配置与非易失配置区分；厂商未明确的耐久、擦写原子性或寿命标为未知
- [ ] 配置失败或掉电后不能通过“上次成功状态”放行输出

## 采样

- [ ] 原始格式、拼接顺序、符号扩展、校准读取和公式已独立核对
- [ ] ADC量化、精度、容差、偏置、量程与有效域分别表达
- [ ] 数值换算采用明确单位，避免 μV/mV、μΩ/mΩ、秒/毫秒错配
- [ ] 建立各通道的更新时间、完成标志、副作用、有效期和一致性策略
- [ ] 均衡、模式切换、启动及唤醒后的受影响样本有失效处理
- [ ] 测试覆盖负数、零、端点、溢出、非法编码、缺样和通道错位

## 保护与驱动

- [ ] 保护阈值、编码、延时及恢复条件分别列出，不把软件阈值直接写入硬件字段
- [ ] 厂商未规定的四舍五入/饱和策略由产品设计明确，不能悄悄变更保护边界
- [ ] 原因状态、锁存状态、允许状态、命令状态与实际驱动状态分别可观测
- [ ] 清除故障前确认故障条件/恢复条件；不会在原因持续时反复开启 MOS
- [ ] 自动保护与手动控制的优先级按该芯片验证
- [ ] 电荷泵、预充/预放及主开关时序、栅极电压与负载条件在实板验证

## 低功耗与均衡

- [ ] 每个电源模式的 ADC、保护、通信、LDO、驱动和 RAM/EEPROM保留范围明确
- [ ] 进入/退出低功耗的命令序列、时间窗和唤醒事件经过验证
- [ ] 主机复位、AFE复位、掉电、看门狗和通信失联均进入可解释的输出策略
- [ ] 均衡允许条件、相邻通道限制、占空/测量窗口、热限制及退出条件落实

## 证据闭环

- [ ] 每个实现关键值可追溯到 PDF 文件与页码，矛盾项仍然可见
- [ ] 单元/主机测试通过仅作为软件证据，不替代 ADC精度、故障注入、热、电气时序及实际功耗测试
- [ ] 产品阈值、容差、FET额定与安全裕量由对应产品验证和批准
- [ ] 厂商勘误、手册冲突和未验证项明确列为开放问题，而非隐藏在默认值中
