# D008 参数页

客户版、内部完整测试版和 Android 版共用“D008 参数”客户端：能力探测、额定容量、SOC、循环次数、SN、加热enable/启停温度、分组默认、ZIP导出与写后核对。内部版额外支持10个新鲜原始样本的零点/增益候选计算和单独保存；客户版不显示校准写按钮。

客户端明确支持固件参数协议 v1/v2，不猜测未来版本。`0x2E00` magic 为 D008，32位低字寄存器前置。v2 在 capability bit6 声明均衡参数，客户端读取并导出 `0x2E70..0x2E73` 的 enable/start voltage/start delta/stop delta；当前未增加均衡编辑控件。加热 `0x2E20` 整组3字，温度 `(℃+40)*10`；校准 `0x2E24` 整组4字；SN暂存 `0x2E50` 分4帧，每帧17字节，然后 `0x2E40` 提交 generation，不要求提高 MTU。保护参数沿用现有页面。

**配套固件当前为参数协议 v2 / Config schema 4，不迁移旧 Config 格式，升级首次启动恢复 Config 默认。请先用本上位机读取旧固件并导出软/硬保护参数留存，升级后人工核对重设。ZIP不自动导入。** 旧固件仅备份已支持参数，拒绝新增写命令；超时单独报告。部分读失败仍可导出且明确错误项，不含密码/access token/SN generation。

客户版修改需要高级解锁，任务与既有OTA/轮询互斥并复用BmsClient锁。换设备必须先读新设备。保存失败/超时先重新读取，不要盲目重复写。分组默认只影响指定参数，不清SN、校准或日志。

校准使用外部仪表提供参考电流，放电正、充电负，单位mA；先无电流采零点，再稳定已知电流计算增益，再明确保存。软校准不替代AFE硬件阈值/Rsense；不得仅凭软件测试认定实板保护验收。
