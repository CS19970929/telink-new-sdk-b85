# MOS 无人值守监控

客户版与内部完整测试版共有顶层 **MOS 监控** 页签。连接后默认勾选“自动监控并写盘”，
无需另点开始。保存目录：`%LOCALAPPDATA%\BmsAssistant\MosMonitor\<会话>`。
点击“打开记录目录”取得 `mos_*.jsonl` 和说明文件；列表只显示最近300条，文件包含全部记录。
“清空列表”保留文件。取消勾选会记暂停缺口；关闭程序停止监控。磁盘写入失败会明确提示并停记。
每10MiB自动分卷，不自动删除历史；长时间使用需保留足够磁盘空间。

记录种类：`start`（设备身份、端点和原协议日志路径）、`sample`（每次实际显示的电池源值、
电流、电压、温度、三级保护、通信统计及指示变化前值）、`diagnostic`（稍后取得的诊断原字及缺失情况）、
`firmware`（固件状态变化、原因、序号和32K tick）、`gap/resume/end`（暂停、断线、失败、恢复及结束）。
UTC时间保留毫秒，源窗口非原子采样，sample与后续diagnostic按编号关联，不声称同一物理时刻。
JSONL使用UTF-8、每条AutoFlush到操作系统，适合后续脚本/AI分析；不保证突然断电持久性。
原始TX/RX通信日志照常保存，可通过start中的路径关联人为MOS指令。

新固件提供 `0x3400` 独立MOS历史，开发默认与 `BMS_DIAG_TRACE_ENABLE` 同开，量产关闭。
Header16 words，当前变化快照32 words，历史8×32 words；u32低word在前，每word大端。
Header magic=0x4D48、version=1、enabled、capacity=8、recordWords=32、count，
偏移6/8/10/12分别是最新sequence/覆盖数/初始化tick/Build ID，14/15为AFE型号/编译flags。
历史始于0x3430，槽号 `(sequence-1)%8`，序号从1开始，可回绕到0。
记录0/2为sequence/tick；4..9为请求/允许/命令/命令有效/driver/driver有效；10/12为充放阻断原因；
14..18为FLAG1/FLAG2/BSTATUS2/backend/guard；19采样有效；20/22电流mA/测量tick；
24..27三级保护/型号；28..30前driver/前有效/有前值；31为SH BSTATUS1或DVC原driver字节。
无变化时每次电池轮询增加一次48-word读取；有变化时只读新增槽和尾Header，每请求≤125 words。
占用既有请求锁、串口20ms间隔及超时；OTA先取消监控并等待读取退出。

旧固件自动降级为当前0x2A80诊断与界面源值记录，明确提示轮询之间可能漏记。
新固件关闭历史时仍读当前诊断。新协议读写边界在固件 `docs/MOS_MONITOR.md` 维护，
Windows/CLI/Core复用 `Shared/BmsMosMonitor.cs`，没有第二套通信协议；Android没有新增本页UI。

“AFE报告关”“命令关”“软件未请求开”分别显示。driver或辅助样本无效时标未知；
断线和电池数据超过5秒未更新也让MOS灯显示未知。
软件/硬件保护、通信资格、温度、参数等由固件原因位显示；SH相关原始FLAG提示时序关联。
请求和命令仍开但AFE报告关且无原因时显示“原因未确认”。全部证据均不等于Gate/Vgs实测，
不能仅凭零电流认定实际关断。恢复时仅连续监控、无缺失且时间可判定的事件显示采样计时差。
首次回读、重启、缺失及长时间tick回绕不推断时长。

固件RAM只能保存8条变化，普通suspend保留，深睡/复位/掉电清空；现有约200ms采样可能漏掉更短的硬件脉冲。
客户端校验槽序号，识别覆盖和读取中重启，重连/身份变化建立新会话；boot tick不是唯一启动ID，
同build、tick、序号碰撞的极短复位不能保证识别。
本功能用于先留下证据，再判断并解决异常，不能声称已解决用户现场MOS瞬间变化的根因。

验证入口：`test-diagnostics.ps1` 包含真实共享客户端的短暂关/开、无效样本、原因、覆盖、竞争、复位、
回绕、旧固件降级及实时写盘测试。客户WPF、内部WPF、CLI统一Release构建；离屏WPF检查MOS监控入口及通信计数。
本次没有固件目标编译、镜像生成、OTA或实板验收；正式EXE、哈希和实际验证记录见交付目录。
# 2026-10-09 失效现场更新

新版在“MOS 监控”显示有效关命令计数、关闭命令持续时间、恢复回读过程，以及最近 AFE 失败步骤。
具体步骤包含寄存器/测量读取、MOS 写入/校验、单体范围、VADC/CADC 数据超过400ms、恢复清标志等。
同时保存本次 FLAG2、ADC 数据年龄、采样耗时、底层错误码和 CRC/重试累计；
`firmware.FailureWords` 和 `diagnostic.failureCurrent` 保存完整原字，可离线复查。
旧固件自动降级，保留 MOS v1；新增 `[0x3700,0x37A0)` 为只读扩展，逐槽序号、boot和Build ID匹配才关联。
计数只计算本会话连续读取中“请求仍开而有效命令开→关”；启动基线、初次历史回读、无效命令不计。
关闭命令与 AFE 报告分开计时，按32000 tick/s换算，均不是物理 Gate 时长。

普通双击后连接 COM3/115200，保持“自动监控并写盘”。台架可显式运行：
`BmsFactoryTest.Windows.exe --monitor-serial=COM3 --monitor-baud=115200 --monitor-mac=A4:C1:38:86:8B:DF`。
工具自动连接并核对MAC，进入MOS页持续记录；目标不符时断开并报错。客户版也支持相同参数。
每次关断可能产生多条状态记录，应按sequence和命令边沿合并分析，不能把每条日志当作一次关断。
