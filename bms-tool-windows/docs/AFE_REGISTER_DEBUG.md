# AFE 全寄存器调试（内部测试版）

2026-10-19 实现；执行过的验证与未关闭项以该轮交付记录为准。

入口在 `BmsFactoryTest.Windows` 的“AFE 全寄存器”。客户版保持现有硬件保护参数页；
两版仍使用原 35-word 持久事务，新增寄存器调试不写 Config/State/Event。

## 配套固件

四产品 monorepo 的 `bms_tools/configure_parameters.py` 是源码设置入口。
它可编辑软硬件保护默认、精确分流器比例，查看原厂位表并导出调试 JSON。
在所选产品源码配置中启用 `BMS_AFE_REGISTER_DEBUG_ENABLE=1`，再按授权构建开发固件。
普通开发和量产均默认关闭；production 同时启用此开关会编译拒绝。

目录来自原厂资料库：DVC1124-2 RM V1.2 / DS V1.1 的 145 地址，
SH36735XX CV1.0A 与 CV0.2C 各 90 地址。旧版仅离线对照，字段保留原页、访问属性和说明。
SH3673510 与 SH3673520 共用寄存器家族，实际板型以配套固件和实装为准，
窗口显示的型号是固件编译声明，不是硅版本探测。

桌面目录作为内部版嵌入资源发布，不依赖运行目录中的可变 JSON。
目录及固件读写掩码由固件仓库 `bms_tools/afe_register_catalog.py --host-root <本仓库>`
同一次生成。目录 ID 不一致时拒绝写入；不能手改其中一份规避检查。
物理型号/版本、原文矛盾、BOM 和实板验收仍须单独核实。

## 使用

1. 未连接时可在窗口选择 DVC/SH 离线查阅。连接设备后点击“读取设备 / 新会话”；旧固件或未启用调试的固件返回不支持。
2. “读取全部安全地址”逐项读寄存器，跳过 RC 和原文地址未决项；它不是同时刻快照。
   选中寄存器可查看每个字段/位的值和原厂定义。
3. 断开充电/负载，确认电流在 ±200mA 内，再进入调试冻结。
   固件确认 MOS/均衡关闭后暂停正常采样/控制；不代表 Gate/Vgs 已实测关闭。
4. 在字段行输入原始编码，点击预览，再按字段写入并读回。CAS 检查旧字节，
   修改后的目标保留其它位。失败或应答丢失不能自动重试，先重新读状态。
5. 读清除寄存器须在冻结中显式读取；配套底层只尝试一次，CRC 错误不会自动重读消耗标志。
   RO/保留/模式/清标志/触发/FET/GP/均衡命令不开放通用写入。
   DVC `0x90` 起始地址在原文有矛盾，仅显示定义，不实际读取。
6. 导入源码调试文件时先校验 schema、目录 ID、型号和掩码，显示逐项计划，
   每次允许 1..32 项；这是非原子临时操作，失败立即停止，已写项可能生效。
7. “恢复源码 / 持久配置”完整恢复后端，再由正常 guard 确认完整采样/保护/控制。
   断连、授权超时、关闭窗口只撤销授权，保持冻结；重新开会话可恢复，或重启设备。
   不自动清除软件活动故障、用户请求、远程禁止或校准参数。

原始修改是临时 RAM；长期保护参数用原 AFE 硬件保护页保存。
固定字段的源码预设仅覆盖稳定字段，避免成为保护 profile 的第二个所有者。
窗口可导出带时间、实际值/未知状态、型号、目录 ID、版本和页码的 JSON 快照。

## D014 精确电阻

固件计算使用 `2000/3 µΩ`，旧 `0x2525=667` 仅作整数微欧显示。
两版硬件保护页可选读取新增 `0x252C/0x252D` 的分子/分母。
旧设备不提供追加窗口时，明确标注“整数模型，精确比例未知”，不从 667 猜实装。
SH 恢复回差按实际量化阈值校验，允许 requested 与 recover 相同但实际阈值更高的合法配置。

按 SH V1.0A p37..38，OCD2 请求 15A 时，精确模型对应 10mV/code0；
667µΩ 近似会得到 10.005mV 并进入 20mV/code1。
SC 依赖 OCD2 原始电压档位及 2/3/4/6 倍数。窗口显示按精确比例换算的名义值，
不包含 AFE、分流器和板级误差，也不替代实测动作电流。

## 协议与证据

沿用 Modbus function 0x42，新增子命令：INFO=0x10、READ=0x11、BEGIN=0x12、
WRITE=0x13、RESTORE=0x14。成功响应分别为 18/8/6/8/6 字节，错误统一 6 字节；
原授权 60 秒和旧 0x01..0x06 不改动。最长响应 18 字节，适用于 BLE MTU=23。
公共接收器同步增加完整帧长度推断；读取、CRC、地址、长度及写后读回均检查。
