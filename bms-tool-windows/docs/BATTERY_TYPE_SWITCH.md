# 整套 LFP/NMC 参数切换

App 客户版从设备页“进入服务设置”输入 `hs456` 后仍停留在设备页，明确展开“业务参数、SOC 与电池类型”和“软件/硬件保护”两个入口；断开设备自动退出服务模式。这样不会让密码确认点击落到跳转后的危险按钮。Windows 客户版先用现有高级功能密码解锁，再到业务参数页选择类型；内部版的切换按钮也要求密码。

切换前核对实际电芯类型，断开充电器和负载。软件/硬件保护、加热/均衡阈值、SOC 全部算法阈值与 OCV profile 由固件整体保存；容量、均衡许可、实测校准、身份和历史状态保留。当前 SOC 继续按原静置算法修正。D008 24S 不支持 4.20V 三元切换。

共用客户端先检查参数能力 bit8 与 `0x2EA0` 接口 v1，旧固件不发送写命令。发送前从 `0x2E2A..0x2E2E` 等待三个不同时间戳的新鲜静置电流样本，并按设备当前 `current_deadband_ma` 判断；样本未就绪或仍有充放电电流时不发送命令。整条 `0x2EA8` 请求为 17 bytes，适配 MTU=23；无自动重试。固件返回 `0x04` 后，客户端重新读取样本、MOS guard 和切换状态，区分采样/通信门禁与 CFG2/SCP1 保存或 AFE 应用失败。成功后读回类型、软件、AFE requested/effective、完整 SOC profile 和均衡，刷新/失效原编辑值，避免旧类型数据回写。密码在 TX/超时日志隐藏；本版本没有可改密码的 Flash 字段。

能力 bit9 与 `0x2EB0` 接口 v1 提供完整 SOC profile。Android 与两个 Windows GUI 可读取、编辑和保存三项 SOC 调参、有效电压范围、满/空端点、压差/末端阈值，以及最多 15 个 OCV 点。客户端每次最多暂存 4 word，最后用带 generation 和 `hs456\0` 的 5-word 命令一次提交；保存后完整读回比对，不自动重试。恢复默认只恢复当前电池类型的 SOC/OCV，不重置当前 SOC、容量或历史。

Android 保护页已移除内嵌小滚动区，软件/硬件页签及当前参数组统一置于整页 `ScrollView`。电池类型和 SOC/OCV 编辑移到业务参数页。Android 设备页与两个 Windows 窗口标题显示 `App Commit`，CLI 使用 `bms-cli version [--json]` 查询；构建工作树不干净时追加 `-dirty`。

必须配套固件 `docs/BATTERY_TYPE_SWITCH.md` 描述的实现。本轮实机只复现旧版导航、滚动和点击穿透风险；未执行离线测试、Windows/CLI/Android 编译、修改后 UI 或实板参数写入验证，没有新 EXE/APK。该工作树之前已有大量未提交修改，提交时只纳入本功能文件和对应增量。
