# 客户电流校准操作说明

适用配套固件的 D008、D011、D013、D014。客户版和内部版均支持“仅校准零点”和“两点校准”；内部版额外显示两点原始样本和系数。具体上位机编译版本、源码状态及检查结果见发布包 `manifest.json` 和 `test-results.json`。本功能尚未完成实板精度验收，上位机包不包含固件 BIN。

## 准备

- 使用独立电流表，确认测量的是流经 BMS 分流电阻的同一路电流。负载或充电器的设定值不能直接作为校准参考。
- 使用已声明支持“持久零点两点校准”的配套固件；旧固件会被向导拒绝，不会发送校准写入。
- 选择本产品允许范围内、能稳定保持的加载电流。界面至少接受 1 A；应优先使用较大稳定电流，但不能将界面的软件输入上限理解为产品额定电流。
- 保持一台上位机操作一块板；采集过程中不升级、不重启、不改参数或 MOS 许可。客户版沿原入口解锁高级功能。

## 仅校准零点：两步完成

适合实际没有电流却显示少量电流，或已完成增益校准、只需重新校正零点的情况。它不能修正随电流增大的比例误差。

1. 连接设备，打开“业务参数”的“电流校准”。客户版先解锁高级功能。断开充电器和负载，确认实际电流为零，点击“① 采集零点”。
2. 保持实际电流为零，点击“仅保存零点（保留增益）”。上位机重新采集稳定零点后保存，等待“零点已保存并读回，原增益保持不变”。

不需要输入电流值或选择方向，不需要采集加载点；错误或空白的电流输入不会影响此操作。首次采集不写入参数，点击仅保存零点才写入。保存前会再次采样检查，因此通常需要再等待数秒；不能仅凭上位机显示为零认定没有真实电流，须确认充电器和负载已断开。

仅修改原始电流零点，增益逐位保持本次开始时的设备原值，包括原有合法的 0.1～10 倍增益。沿原协议整组写入零点和未改变的增益，不改变参数布局或恢复其他参数。采集期间若参数被其他工具改变，会拒绝保存。采集加载点后该按钮暂不可用；需要改为仅校准零点时先取消并重新开始。

## 两点校准：零点加一个加载点

1. 连接设备，打开“业务参数”，找到“电流校准”。
2. 断开充电器和负载，确认电流表为零，点击“① 采集零点”。上位机自动备份原校准参数，并采集20个新鲜样本。
3. 接入稳定充电或放电，选择方向，输入电流表实测电流的正数 A 值，例如 `19.985`，点击“② 采集电流点”。不要输入负数，不用填写 ppm。等待读数稳定再采集。
4. 候选生成后点击“③ 保存校准”，等待参数读回和新样本公式核对完成。点击“导出校准记录”保留备份。

只需零点和一个加载点，不要求充放电分别校准。每次采集通常数秒，20秒仍未收集完整则停止；整个向导超过10分钟自动结束。采集不写Flash，点击相应保存按钮才整组写入。修改参考值或方向后，必须重新采集电流点。

## 状态和失败处理

| 提示/操作 | 含义及处理 |
|---|---|
| 候选已生成，尚未保存 | 设备仍使用旧参数，可取消 |
| 已保存并读回 | 参数和一个新鲜样本的计算公式已核对；不等于精度验收 |
| 电流波动或持续漂移 | 稳定负载/充电器后重新开始，不反复保存 |
| 零点残差超范围 | 确认没有真实电流，检查接线、接地旁路和采样回路 |
| 增益异常/方向不一致 | 核对 A 单位、方向和外部电流表；不要人为放宽门限凑数 |
| 采样失效、连接改变、授权失效 | 当前候选作废，确认设备状态后重新开始 |
| 可能已写入/读回失败 | 实际结果未知，先重新读取设备参数；不要自动重写或恢复默认 |
| 取消 | 写入前取消不改变参数；写入后取消可能已经保存，不能撤销或反复重写；完成读回核对后取消也不会撤销保存 |
| 恢复本次校准前参数 | 仅同一次有效连接、连续采样时钟、紧接上一授权代次、设备身份和参数仍匹配时可用；恢复后也会读回 |

候选及原参数备份在程序内存中，关闭前应导出记录。断开重连后不自动将旧备份写入当前连接，避免写错设备。“恢复本次校准前参数”与“恢复默认”不同，不清除 SN、SOC、容量、均衡或保护参数。

重新上电后，BMS 使用 Flash 中最后完整提交的零点和增益；未保存的采集结果不会自动保存或恢复。仅零点校准不改变原增益，两点校准则保存新零点与新增益。设备重启、链路失效或其他工具取得新授权后，旧候选/恢复备份作废，需重新开始；不能仅凭 SN 相同判断还是原会话。上位机不会在重连后自动重写参数。

固件没有独立启动序号；恢复检查同时使用采样时钟和现有递增授权 token。授权代次跳变或16位回绕时采取保守拒绝；不要为恢复旧备份连续点击授权或重启。检测到连接失效后不会向恢复后的设备发送旧 token 的 CLOSE。保存结果未知时，先读取设备参数并保留记录，由工程确认，不以再次保存作为确认手段。

## 保存后的检查

重新检查零电流、一个小电流及另一个较大电流；有条件时检查相反方向，并重新上电复查。最终验收使用独立电流表，不能只看保存成功或校准时的同一个点。若同方向不同电流仍偏差明显，或冷热变化明显，应保留记录交由工程排查，不能靠增加客户操作步骤保证准确。

此功能校正软件测量及其消费者，不修改 AFE 硬件保护阈值、Rsense、协议缩放或 Flash 布局。D008 新固件保留 CAMZ和启动检查，但不再叠加 RAM 软件零点；升级前后及回刷旧固件时电流行为需重新核对。

## 内部检查入口

编译后可使用 `test-current-calibration.ps1 -CustomerAssembly <客户版DLL> -InternalAssembly <内部版DLL> -EvidenceDirectory <源码树外目录>`。它在内存 Modbus 对端上检查四种产品身份、零点有符号取整、原增益保留（包括两点候选范围外的合法旧值）、整组写入与读回、能力/失效采样/参数变化/取消/读回不一致拒绝路径，并对两版窗口离屏检查两个保存入口的门禁。它不创建串口或 BLE 连接，不代替实板或 Flash 掉电验收。

2026-10-16 源码复审补充：覆盖写入后取消且不自动重试、原客户端断线恢复后仍拒绝旧记录、重启后重新读取系数、RAM 授权失效、自然 tick 回绕和空闲取消后的重复事件。模拟对端的“重启保参”不代表真实 Flash 掉电通过。真实记录写入/提交、CRC 和加载边界以固件源码及实板验收为准。
