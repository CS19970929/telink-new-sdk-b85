# 客户电流两点校准操作说明

适用配套固件的 D008、D011、D013、D014。客户版和内部版流程相同；内部版额外显示原始样本和系数。2026-10-15 本轮仅完成源码和异常路径审查，未编译或打包 EXE，未生成固件 BIN，也未进行实板精度验收。现有已发布 EXE 不代表已经包含此功能。

## 准备

- 使用独立电流表，确认测量的是流经 BMS 分流电阻的同一路电流。负载或充电器的设定值不能直接作为校准参考。
- 使用已声明支持“持久零点两点校准”的配套固件；旧固件会被向导拒绝，不会发送校准写入。
- 选择本产品允许范围内、能稳定保持的加载电流。界面至少接受 1 A；应优先使用较大稳定电流，但不能将界面的软件输入上限理解为产品额定电流。
- 保持一台上位机操作一块板；采集过程中不升级、不重启、不改参数或 MOS 许可。客户版沿原入口解锁高级功能。

## 正常操作

1. 连接设备，打开“业务参数”，找到“电流两点校准”。
2. 断开充电器和负载，确认电流表为零，点击“① 采集零点”。上位机自动备份原校准参数，并采集20个新鲜样本。
3. 接入稳定充电或放电，选择方向，输入电流表实测电流的正数 A 值，例如 `19.985`，点击“② 采集电流点”。不要输入负数，不用填写 ppm。等待读数稳定再采集。
4. 候选生成后点击“③ 保存校准”，等待参数读回和新样本公式核对完成。点击“导出校准记录”保留备份。

只需零点和一个加载点，不要求充放电分别校准。每次采集通常数秒，20秒仍未收集完整则停止；整个向导超过10分钟自动结束。候选生成前不写Flash，点击保存才整组写入。修改参考值或方向后，必须重新采集电流点。

## 状态和失败处理

| 提示/操作 | 含义及处理 |
|---|---|
| 候选已生成，尚未保存 | 设备仍使用旧参数，可取消 |
| 已保存并读回 | 参数和一个新鲜样本的计算公式已核对；不等于精度验收 |
| 电流波动或持续漂移 | 稳定负载/充电器后重新开始，不反复保存 |
| 零点残差超范围 | 确认没有真实电流，检查接线、接地旁路和采样回路 |
| 增益异常/方向不一致 | 核对 A 单位、方向和外部电流表；不要人为放宽门限凑数 |
| 采样失效、连接改变、授权失效 | 当前候选作废，确认设备状态后重新开始 |
| 可能已写入/读回失败 | 实际结果未知，先重新读取设备参数；不要自动重写或恢复默认 |
| 取消 | 停止未完成的操作；若写入已开始，不能据此认定参数未保存 |
| 恢复本次校准前参数 | 仅同一次连接、设备身份和参数仍匹配时可用；恢复后也会读回 |

候选及原参数备份在程序内存中，关闭前应导出记录。断开重连后不自动将旧备份写入当前连接，避免写错设备。“恢复本次校准前参数”与“恢复默认”不同，不清除 SN、SOC、容量、均衡或保护参数。

## 保存后的检查

重新检查零电流、一个小电流及另一个较大电流；有条件时检查相反方向，并重新上电复查。最终验收使用独立电流表，不能只看保存成功或校准时的同一个点。若同方向不同电流仍偏差明显，或冷热变化明显，应保留记录交由工程排查，不能靠增加客户操作步骤保证准确。

此功能校正软件测量及其消费者，不修改 AFE 硬件保护阈值、Rsense、协议缩放或 Flash 布局。D008 新固件保留 CAMZ和启动检查，但不再叠加 RAM 软件零点；升级前后及回刷旧固件时电流行为需重新核对。
