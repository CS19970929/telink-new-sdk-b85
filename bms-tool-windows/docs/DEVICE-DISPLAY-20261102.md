# 首页身份与离线显示

第一轮界面调整：客户/测试版首页底部同时显示硬件版本、软件版本、BMS序列号和设备固件Build ID（含dirty与编译模式），来源与设备信息页一致。客户版移除底部通信统计，并且不创建业务参数中的D015配置页；测试版保留两项。后台通信计数继续服务故障定位。

## 第二轮：8秒通信超时清空

两版正常轮询为1s，单次Modbus响应最多4s，UI的350ms定时器独立于异步轮询。每个BmsClient分别用Stopwatch记录最后一次通过CRC、地址、功能与长度检查的正常响应；原始字节、CRC错误、非本从站报文、Modbus异常应答不刷新。连续8s无正常响应即清空；手动断开或更换连接立即清空。

清空范围为实时电压/电流/温度/SOC/容量/电芯卡片、保护与MOS状态、身份/版本/SN/Build ID、软件保护读回、业务参数、AFE请求/有效值、诊断表/曲线、开线/MOS/运行日志及事件显示、测试版工厂读数。显示使用“—”，MOS状态为未知；SOC图形清零但文字是未知。各参数缓存及AFE写入来源同步失效，不能把旧读回当当前参数。后台诊断日志和已导出文件保留；连接设置、用户目标输入和升级进度继续由各自流程维护。

恢复时先读取身份，再读取电池；参数页需要重新读取才恢复设备值与编辑资格。相同数据再次到来时电芯卡片也重新建立。350ms清空检查在参数、诊断、重连或升级期间仍执行，既有自动重连流程保留。旧连接的AFE/保护/诊断结果不再发布到新连接界面。

回归包含8秒边界、断开、恢复、新读数、参数失效、两版布局及异常响应不续期。现有通信计数测试修正了两个过期断言：接收器丢弃非本从站前缀后按超时计数，产品矩阵现为包含D015的5项；不改变生产通信策略。

验证结果：两版WPF Release编译成功，客户版仅既有CS0649警告，测试版0警告；两版各26项窗口交互/离线恢复检查、两种尺寸与100/125/150%缩放布局通过，已检查两版页脚渲染图。通信/诊断综合回归通过，包含错误响应不续期、重连、取消、轮询与只读会话。未连接或操作实板。
