# D015 运行策略改为固件宏

配套固件提交 c30b83b、084d141、dd8191d、23e7117。快速开发阶段不迁移旧参数格式。

客户版、内部版共用的 D015 基本配置页将下列五项标为“固件宏，只读”，显示设备读回值，禁止单元格编辑和保存。地址及其他产品页面不变；均衡、容量、软件/硬件保护等 Flash 参数继续走原保存与读回流程。

|地址|含义|当前默认|
|---|---|---|
|340A|预充时间|999 ms|
|3410|空闲判断电流门限|100 mA|
|3411|开关闭合时 RTC 唤醒周期|3 s|
|3412|开关断开时 RTC 唤醒周期|20 s|
|3413|欠压保护后深睡等待|3 min|

这些值以设备读回为准，页面不硬编码默认值。修改需重新编译固件。固件拒绝更改这些地址，错误码5。

软件保护每级10条历史已删除，上位机原本没有该历史的显示入口；当前实时软硬件保护状态继续显示，独立100条系统事件继续读取。SOC也不再依赖跨复位SRAM缓存，这两项无需新增上位机功能。

验证：客户版/内部版 Release 编译成功；客户版保留既有 CS0649（_socRecording 未赋值）警告，内部版零警告。两版实际 WPF 窗口离屏测试通过，覆盖五项地址、来源文字、禁止进入编辑及其他参数保留编辑能力。两版均与真实 C 固件模块 host 进程互通，确认宏读回、改写被拒绝、均衡/容量/OCV正常写入，及原身份/采样/校准/SN/分片事务。测试产物在用户 CodexTemp。本次不发布EXE安装包、不连接设备。
