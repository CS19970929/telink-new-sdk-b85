# D015开发版事件日志

固件codex/dev-event-log提供新日志格式1。旧板由CONFIG_RESET_REVISION=6一次性初始化参数、校准、SN、SOC50%、循环和历史；无旧存储读取或迁移，初始化完成后不再上电重置。

客户版和测试版使用同一BmsClient.EventLog.cs及同一事件页源文件；测试版另外显示等级、原始标志、顺序号和存储诊断。新版D015只读3800/3900日志接口，其他产品仍走C008/100，不向其写入D015命令。

信息区3800..380F为4C47签名、版本1、每条16word、容量100、有效条数、标志、最新序号、清空边界及队列/失败/擦除诊断。每次4条/64word读取3900起数据；前后核对条数、序号和清空边界，变化时最多重读一次，不显示混合快照。记录使用高word先/高字节先，电流有符号0.1A、温度有符号0.1℃、SOC0.1%；FFFF电压、8000电流/温度代表未取得测量，不显示为0。

UTC显示为电脑本地时间；未同步日期显示本次运行秒数。按日期、来源、发生/稳定恢复/重复汇总和事件名称筛选；日期筛选排除无日期记录。CSV导出当前筛选，包含读取时设备身份（含固件Build ID）、读取UTC、事件UTC和现场值。读取失败清空旧显示，原有断线/8秒无有效通信清屏逻辑保留。CSV设备文字做公式防护，合法负电流和负温度保持数字。

故障记录合并不改变保护/恢复时序。日志写失败、待安全擦页/空间回收、待写及入队失败都明确显示；近期待写数据还未持久化，突然断电可能丢失，读取日志不会主动写Flash。页头擦除计数只是估计值，不能当作剩余寿命百分数。

验证入口test-event-history.ps1运行两版真实程序集：协议分片/字序/未知时间/变化快照/畸形数据/CSV测试，可接实际C模块的--pc-server进行互操作；离屏WPF测试筛选、布局和断线清屏，不连接设备。客户版、测试版和CLI均构建。固件Flash驱动、擦写寿命与实板验收边界见固件D015/docs/event-history-dev-20261103.md。

固件dev已同步原分支45ba759的200mA/1秒充电确认和a4cd357的样品参数，预充50ms、初始SOC50%，初始化版本保持6。已完成版本6初始化的设备继续读取Flash。协议和本次EXE程序不变；后续直接在原项目目录使用dev分支。
