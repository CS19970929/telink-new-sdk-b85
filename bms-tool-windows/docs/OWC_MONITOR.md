# 一线通与统一监控

客户版以简洁仪表盘A显示关键数据；测试版以紧凑面板B显示更多数据、单体与原始帧。
Windows两版共用CommToolOwcProtocol、CommToolOwcClient、MonitorReading、MonitorRecording与UnifiedMonitorView；
独立模态OwcMonitorWindow已经移除。现有串口/BLE连接、参数门禁和MOS仲裁处理继续复用。

## 连接与能力

主页面选择“蓝牙”“串口”或“一线通”。一线通选择Comm Tool串口并连接，PC侧固定115200 8N1；
普通USB-UART、RS485、BLE不能直接替代Comm Tool接收一线通。
客户版默认自动识别；测试版可在断开后固定A1.3.3或锂神。记录中不切换连接/协议。
适配器连接与有效BMS数据分别判断；接收失败仅重试原COM口，不搜索并替换目标。
自动识别由Comm Tool连续两帧确认。5秒失联清缓存，重新确认；坏帧不刷新有效期。
主页面与记录页切换不会停止接收。断开后接收任务取消并等待有界停止命令；停止失败由设备租约释放上拉。
一线通接收没有参数写入、MOS控制或BMS升级能力，不将其包装成Modbus客户端。
普通连接的MOS许可和设备休眠入口保留；客户版默认折叠“设备操作”，原授权规则不变。

| 格式 | 数据 |
|---|---|
| A1.3.3 | 原有静态信息、实时值、单体和编号；原缩放不变 |
| 标准锂神V1.1.1 | 六字节00/SOC/总压/温度/00/SUM，只显示三项 |
| 本项目锂神扩展 | 六字节电流/SOC/总压/温度/0xC0|故障码/SUM，新增电流与上报故障 |

## 保留字节扩展E1

这属于本项目私有扩展，不宣称第三方仪表兼容。长度、SUM8、MSB位序和原锂神波形保持。
字节0：int8补码电流，1A/bit，正放电负充电，-127~127A；0x80表示无效或超量程。
由0.1A取最近整数，正负半值远离0；双向同时非零也标无效，不溢出回绕或饱和截断。
字节4：高两位固定11，低6位沿用A1.3.3既有故障优先级和码表；故障码00是“无上报故障”，不是物理安全证明。
旧标准两个00不会被解析为0A或无故障。未知保留值仍拒绝；无效电流只隐藏电流，仍可显示有效电量、总压、温度和故障。
锂神实时有效期始终5秒，电流字节恰为3B/3C也不能取得A1.3.3单体的75秒有效期。
BMS选择BMS_PRODUCT_SIF_PROTOCOL=2；BMS_PRODUCT_SIF_LISHEN_EXTENDED默认1，设0恢复原标准两个00。
Comm Tool App需0.2.8或后续支持版本；旧0.2.7不支持此扩展。新上位机仍可显示旧标准三项。

## 长期记录

1. 连接后点击“开始记录”选择目录，默认5秒，可选1/5/10/30/60秒。
2. 记录直接消费解析结果，不解析界面文字；来源、协议、符号、精度、独立单体时间和缺测保留。
3. 有界后台队列256条，写盘错误/积压显式停止，错误不被后续通信刷新抹掉。
4. JSONL逐条刷新，按UTC日期或100000条轮换；UI趋势保留最近24小时，近30分钟逐样本、较早每30秒抽样，最多6000条（含事件），完整数据保留在磁盘。
5. 断线不重复旧值，写缺口；恢复、会话、协议或身份变化创建新段。没有身份的重连不能认定为同一电池。
6. 可添加事件备注、打开历史。最后文件的不完整末行可恢复为recovery_gap；中间损坏报错，不静默跳过。
7. 结束记录等待队列写完；关闭窗口先完成接收停止与写盘。任务结束后导出CSV或Excel。
8. CSV流式导出完整记录并防止文本公式注入；Excel单次最多100000条，超出请用CSV，避免长监控导出耗尽内存。
9. 时间是PC观察时间，跨报文不是原子快照；1A分辨率扩展不适合精密电量积分。当前未计算Ah/Wh。
10. 软件回放和离屏布局不代替24小时实机稳定性、USB插拔、板上波形或真实保护验收。
