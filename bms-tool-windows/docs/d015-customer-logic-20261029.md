# D015 2.4.1 显示同步

配合固件5ca5e51。客户版与内部版共用同一显示筛选：连接D015并取得电池信息/参数后，保护页不显示SOC低保护分类及213C..2140五行。底层仍按65字读取和校验，保留地址与其他产品协议；切换其他产品恢复原显示。低电量由固件独立提示，不将SOC用于保护或MOS关断。
