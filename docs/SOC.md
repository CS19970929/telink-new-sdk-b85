# SOC：当前算法与维护入口

## 当前策略：2026-10-20 / policy v3

四产品共用 `bms/core/bms_soc.c`。本轮完整需求、参数表、曲线来源、采样线诊断、兼容与验收边界见 [SOC v3 重构说明](SOC_REFACTOR_20261020.md)。本文与该说明描述当前源码；旧日期记录及旧板测试不能作为本轮验证结果。

调用链：`app_sample_task()` → 后端完整采样/保护 → feature/MOS 仲裁 → `app_update_soc_from_sample()` → `bms_soc_process_sample()`。电流正放电、负充电；`remaining_capacity_as10` 是唯一内部剩余电量，整数 estimate、容量报告和 display 均由它派生。

- 每个有效电流都按实际毫秒积分，包含 ±200mA 以内；充电电荷效率100%，带符号余数保留。方向证据仍需超过200mA及 profile 的方向门槛。
- 首帧建基准；重复时间不推进；间隔≤400ms才积分；无效输入或更长间隔不补算。电压、温度故障本身不屏蔽仍有效的电流；真实保护独立处理。
- 满电最高单体过线、最低达到门限减200mV、压差≤200mV、可靠充电60秒，并通过新采样线检查。LFP3500mV，NMC4180mV。
- 空电最低单体过线、压差≤300mV、可靠放电5秒，并通过新采样线检查。LFP2850mV，NMC3100mV。真实且仍有电压证据的保护事件有独立端点补充路径。
- 端点立即同步内部电量；所有运行显示每5秒最多变化1个百分点。只有电压判满资格允许目标100%；积分或人工100%无资格时目标99%。保护不等待显示。
- 普通OCV只向下：全部配置串有效，平均电压，电流绝对值≤200mA，压差≤200mV，连续静置60分钟，最近15分钟各串一分钟均值范围≤5mV；均衡和主动诊断激励电压不进入普通OCV窗口。
- LFP任一串进入3200～3400mV（含边界）就禁止普通OCV。非平台区使用模型上界，每30分钟合格时间最多下调1个百分点；每次动作还需新采样线检查。
- SOC不使用温度资格、温度补偿或温度容量修正。原独立温度保护和均衡/加热温度规则保持。
- 无容量学习、自放电假设、静置快清零、多级末段拉低或人为补回1%。循环/SOH沿用经验定义，仅真实积分引起的下降累计放电。

## 配置、状态与诊断

完整50-word模型继续位于 Config/schema 4；策略v3默认由 `bms_soc_profile.c` 唯一定义，产品头中的旧曲线宏不再构造运行模型。旧 profile 可读且保留，不静默转换为v3；显式更新SOC组或内部上位机保存v3后才启用电压校准。

State/schema 5保存整数SOC、放电累计、cycle、原OTA标记及判满资格/配置依据。仅导入同产品ST4/schema 4，旧100%不代表已电压判满。详见 [存储说明](STORAGE.md)。高精度电量、小数余数、显示进度和OCV静置不逐笔持久化；冷启动按保存整数重建。

模型刷新保留高精度电量；容量/SOH基准改变按原高精度比例重算。相关配置、人工SOC、空电端点或高精度SOC低于99%撤销判满资格。

`bms_soc_get_diag()`保留现有布局，给出模型、estimate/display、OCV/rest、端点、循环SOH、ETA和样本原因。废弃学习槽保持零。confidence=25是工程提示，非统计置信度。ETA不作为保护或SOC校准证据。
