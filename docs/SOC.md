# D008 SOC 与两个客户参数

## 计量和显示

`bms_soc.c` 是独立纯 C 算法。额定容量为积分基准。应用接入通过 CRC 的 DVC 电流和新 VADF，算法用无符号毫秒差和上一有效电流计算相邻区间，保留小于 0.1 A·s 的有符号余数。CC2 最长使用 400 ms。相邻两轮采样有效且轮询间隔不超过 400 ms 时，使用上一笔合格电流覆盖完整相邻区间，不因 CC2 相位错开截短。绝对值不超过 200 mA 的电流按零积分（AFE 原始测量保留），与上报零电流区一致。读取失败或轮询间隔超过 400 ms 时断开积分和观察。等效循环按实际放电量累计，SOH 保留报表经验值。

LFP 候选满空参考为 3500/2850 mV，NMC 为 4180/3100 mV。满端使用整包电压包络、近期充电和 30 s 连续合格 VADF，截断或停充可使用已建立的近满历程。正常空端使用有效放电、低压和 5 s 持续证据。孤立跌落不会校准，较大压差的可信 UV 候选还需完成一次有界 COW 和正常 VADF 复核。实际 MOS 保护独立执行。

未确认端点时显示目标限制在 1–99%。普通每累计 5 s 有效采样间隔走一步，可信末段每 2 s 一步且预跟随最多 4 个百分点。电流采样间断时暂停显示计时，恢复后接着累计。确认后内部电量立即锚定，显示每秒最多一步，反向电流撤销追赶。充电时显示只升，放电时只降。静置允许确认后的同向追赶和保守下调。

已有 State 直接恢复电量和显示。新板的第一个合格无负载样本可初始化估值，LFP 平台使用 60% 候选值。运行静置校正需温度、压差、电流以及电压极值和均值稳定，LFP 3200–3400 mV 平台跳过。初次需 90 min，持续合格时每 30 min 最多下调一个百分点。

## 参数协议 v2

| 项目 | 格式 |
|---|---|
| 能力 | `0x2E02` 符合 `capabilities & 0x1000` |
| `SOC100` / `SOC0` | `0x2E18/0x2E19` 两个 mV 16-bit 大端字 |
| 读取 | `0x03`，可整对读取 |
| 写入 | `0x10` 从 `0x2E18` 一次写两词，仅单播，成功后可整对读回 |
| SOC 范围 | LFP 3400–3750 / 2000–3150 mV，NMC 4050–4200 / 3000–3300 mV，满空至少相差 300 mV。在线设置还须满足当前 SW/AFE 启用的单体与整包保护阈值 |
| 装配 | `0x2EA2` 只读，LFP 为 1，NMC 为 2 |
| 遥测 | `0xD124` 为显示百分比，`0x1005` 读取内部估值，`0x2319` 只读循环次数 |
| 手动校正当前 SOC | `0x1005`，`0x06` 或 `0x10` 单字写入 `0–100` 的整数百分比，仅单播 |

端点修改经 Config 校验、提交和发布，只重开端点观察并取消旧配置下的追赶授权。额定容量修改保持电量比例与显示，State 记录的容量用于重启等比例恢复。

LFP 空电端点低于 2700 mV 时，State 在原 `endpoint_basis` 字段内用第 27 位（从 0 计）区分低压扩展，电压字段记录相对 2000 mV 的差值。已有端点的编码保持兼容。

上位机手动校正先提交 State，成功后立刻同步内部估值和显示，重启从该记录恢复。人工设为 `100%` 可保留满电显示，后续按原放电和配置变化条件撤销。人工校正保留累计放电量和循环次数，软件及 AFE 保护仍按各自条件执行。

既有客户端按能力加载两项端点输入并整对提交，界面显示原实时窗的 `0xD124`。

[纯 C 回放格式](../tests/soc/traces/README.md)覆盖合成 Golden Replay。电芯曲线、弱串、COW、温漂、零偏和运行节拍需按出货装配实测。
