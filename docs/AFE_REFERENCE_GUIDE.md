# AFE 资料库使用与开发验证

本指南用于 AFE 寄存器、采样换算、校准、保护/恢复、MOS、均衡、低功耗、通信，以及会改变 AFE 有效配置的默认值、持久化和 OTA 更新。先进入 [资料库导航](../references/afe/README.md)。资料已存入项目，原包字节保持不变；[固定提交审查](afe-audit/20261006-0aaa8429/README.md) 记录 `0aaa8429` 的结论，不代表未来代码验收。

## 开发步骤

1. 从产品 `sources.txt`、生产编译宏和实际调用链确定当前后端、硬件假设及有效配置来源。结合产品 reference、BOM/原理图/实装确认精确型号后缀和手册适用版本；缺少装配或硅版本证据时写明未确认。
2. 阅读 [本轮更正与补充](afe-audit/20261006-0aaa8429/资料库更正与补充清单.md)，再查对应 PDF。中文摘要、registers.json 和逐页文本用于定位；寄存器位、默认/RW/清除、副作用、单位、公式、保证范围及通信时序以对应版本原 PDF 为依据。表格、图片、脚注和丢失公式回看页面。原文矛盾保留两侧证据，等待厂家澄清或明确测量结论。
3. 分别追踪编译默认、设备持久化、OTA 更新编号和运行时写入，计算最终寄存器及物理阈值/延时。对照 [四产品配置矩阵](afe-audit/20261006-0aaa8429/四产品有效AFE配置.md)，旧设备同编号可能继续保留原参数；矩阵不是设备实读或量产签核。
4. 对修改涉及的本轮发现建立独立回归，期望来自原 PDF 或明确产品需求，记录文件/版本/PDF物理页和取整/范围条件。重新检查实际编译路径和失败恢复；测试通过不能替代物理恢复证据、Gate/SOA、Flash掉电和低功耗验证。完成标准是结论具有原页、当前源码位置、执行证据及剩余限制。

## 本地工具

从仓库根目录执行；Python标准库即可，两个工具只读资料：

```powershell
python -X utf8 -B references/afe/AFE_完整开发参考库_20261005/tools/search_reference.py --source DVC1124_2_RM_V1_2 CC1
python -X utf8 -B references/afe/AFE_完整开发参考库_20261005/tools/search_reference.py --source SH36735XX_CV1_0A SCT
python -X utf8 -B references/afe/AFE_完整开发参考库_20261005/tools/verify_pack.py
```

`-X utf8` 避免 Windows 默认 GBK 导致原检索工具读 UTF-8 清单失败；`-B` 避免产生 Python 缓存。原工具文件保持原包字节。`verify_pack.py` 检查结构、来源哈希、索引和链接；它的 PASS 不覆盖完整语义或硬件安全，不能代替本轮原 PDF 独立审核。需要截图、第三方解析缓存或脚本输出时重定向到 `%LOCALAPPDATA%/CodexTemp/`，不写入原资料目录。
