# D008 源码保护参数配置

自 2026-10-13 起，D008 的保护默认值统一在 [d008_protection_config.h](../bms/products/d008/d008_protection_config.h) 编辑。2026-10-14 已按保护项连续排列，并加入 SOC/OCV、容量和业务默认；D011/D013/D014 也各有专用配置文件，当前操作见 [四产品参数与类型切换](BATTERY_TYPE_SWITCH.md)。

## 直接修改的位置

| 区域 | 配置项 | 单位/说明 |
|---|---|---|
| 一、总开关 | `DVC1124_SW_PROTECT_ENABLE`、`DVC1124_SW_TEMP_PROTECT_ENABLE`、`DVC1124_HW_PROTECT_ENABLE` | 保留原台架覆盖和生产构建必须全部开启的约束 |
| 二、软件保护 | `D008_SW_*` | 完整 65-word 软件参数：单体/总压、充放电过流、高低温、MOS 高温、压差、低 SOC |
| 三、AFE 硬件保护 | `D008_AFE_*` | 独立启用项、单体过压/欠压、两级充放电过流、放电短路；没有软件的 First/Second/Third 分级 |
| 四、编译期检查 | 16位范围、总压单位、欠压恢复关系、启用项范围 | 在赋给 uint16_t 前检查；原运行参数校验继续保留 |

软件和 AFE 电压使用 `*_FOR(c)`：条件左侧是 LFP，右侧是 NMC；编译默认与在线切换共用这些数值。串数/类型仍由 `d008_product_profile.h` 和构建选项选择。Rsense、GPIO、watchdog 和通信保持板级入口。

- `_MV`：mV。
- 软件总压 `_CELL_MV`：按单串折算的 mV；实际存储仍为 `(_CELL_MV / 10) * 有效串数`，单位 10mV。填写 10mV 的整数倍，不能把整包电压直接填入此项。
- `_A10`：0.1A，例如 100=10A、200=20A。
- 软件 `_FILTER_10MS`：10ms，例如 100=1s。
- AFE `_MS` / `_US`：ms / us，分别编辑，不再从软件滤波延时推导。
- 温度 `_X10`：`(摄氏度+40)*10`，例如 55℃写为 `(55+40)*10`。
- AFE 短路 `_SC_THRESHOLD_MV`：分流电阻两端电压；不是单体电压。实际电流按板级 Rsense 换算。

## 首次烧录与已有参数

空白板没有有效 Config 记录时，`bms_config_store_init()` 经 `bms_config_defaults()` 分别调用软件默认和独立 AFE 默认构造，再按原校验、保存、应用与输出门禁处理。Flash I/O错误不会被当成空白板覆盖。

已有有效 Config 记录时，保存值优先；修改源码后仅重烧 APP 不保证恢复默认。需要更新时使用原 SW/AFE 分组更新选择及一次性标记。修改软件组不会覆盖 AFE 组，反之亦然。CFG2 payload、schema 3、外部协议、缩放、Flash分区、启动/OTA边界及校准/SN/事件均未改变。
