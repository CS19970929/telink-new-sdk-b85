# TC32 CPU 汇编自检说明

`bms_selftest_cpu_tc32.S` 保存调用者期望保持的上下文，对 r0～r11 依次写入 `0x00000000`、`0xFFFFFFFF`、`0xAAAAAAAA`、`0x55555555` 和代表性的 walking-1/walking-0 模式，立即比较并通过条件分支汇聚结果；同时验证算术/比较标志、前向/后向分支及 `tjl` 调用返回路径。

测试在 BSS/DATA 初始化后、C 主流程之前执行，失败不进入正常应用。r12、SP、LR 因 TC32 ABI 和测试函数自身控制流不能作为普通数据寄存器做同等破坏测试：SP 由链接边界/guard/水位间接检测，LR 由真实调用返回间接覆盖，r12 列为残余风险。最终必须以 `tc32-elf-objdump` 反汇编确认指令和符号未被优化/链接删除，并在目标芯片上执行故障注入。
