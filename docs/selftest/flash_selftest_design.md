# Flash 自检设计

链接器保留固定 64 字节 Manifest，后处理脚本从 ELF 符号取得真实偏移，写入魔数、版本、CRC 参数、两段范围、原始镜像长度和 Manifest 自身 CRC。应用 CRC 跳过 Telink 可变头前 32 字节和 Manifest；最终 BIN 再由 `tl_check_fw2.exe` 写入/校验 Telink 原生长度和 CRC。

启动阶段验证 Manifest 结构并完成镜像 CRC，未通过不得开放输出。运行阶段复用同一范围，以小块读取避免阻塞 BLE/保护任务；完成一轮才比较，随后重新开始。OTA 活动时暂停运行扫描，候选镜像由离线工具和下一启动检查覆盖。

该机制检测被覆盖程序区的随机位翻转和错误镜像，但不等同密码学签名，不能防止能同时重算 CRC 的恶意修改；安全启动/签名属于另一个安全目标。
