# RAM/栈自检测试步骤

1. 由 MAP/NM 确认专用区和 `_bms_stack_guard_start_/_end_` 均位于 SRAM，且不与 DATA/BSS/栈边界重叠。
2. 正常运行若干扫描周期，确认测试区内容恢复、应用数据和 BLE 连接无异常。
3. 测试构建注入 RAM 结果错误，确认在输出开放前或 100 ms 周期内进入安全态。
4. 用调试器破坏安全变量或其反码，确认内部数据故障。
5. 在隔离固件逐步增加调用深度，记录最低栈余量；触碰 guard 后确认故障和输出波形。
6. 复位、重刷生产镜像并验证恢复。

当前仅完成第 1 项的自动布局检查，其余需目标板执行。
