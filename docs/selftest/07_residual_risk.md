# 残余风险与待确认项

| 项目 | 不能确认的原因/位置 | 安全影响 | 最小补充信息 | 保守处理 |
|---|---|---|---|---|
| PD7 `AFE1_PRO_EN` 极性 | 软件无原理图和有效电平定义 | 误驱动可能改变保护链 | 原理图、BOM、AFE/外围手册 | 早期不主动翻转，其他输出全关 |
| 独立时钟测试 | system tick/Timer0 同源；未找到独立测频寄存器方案 | 共因漂移可能漏检 | TLSR8258 时钟安全资料或外部基准 | 只检测停止/严重调度异常，不声称频率覆盖 |
| WDT 复位原因 | 未找到经过项目确认的 reset-cause API | 无法可靠区分 WDT/其他复位 | 芯片寄存器定义和板测 | 致命故障用模拟保留寄存器粗粒度锁存 |
| CPU r12/SP/LR | ABI/调用返回和栈使用限制直接破坏性测试 | 部分寄存器位故障覆盖不足 | TC32 安全库/ABI 审核 | SP 做范围/guard，LR 用调用返回间接测试 |
| 全 RAM | 在线破坏测试会损坏协议栈/应用状态 | 未覆盖 RAM 区故障可能漏检 | RAM 安全分区设计、启动前可用范围 | 仅测试专用区和关键正反码，明确覆盖边界 |
| IRQ 栈 | 启动文件栈共存但未建立独立破坏测试 | 中断深度溢出可能漏检 | 最坏中断嵌套和栈分析 | 全局 guard、水位和链接余量，需板级压力测 |
| 外部 MOS 粘连 | BSTATUS3 主要是 AFE 内部反馈 | 功率管短路可能不被软件反馈检测 | 栅源/电流独立反馈和原理图 | 命令全关；依赖硬件二级保护，必须做夹具测试 |
| ADC 阈值 | 通道分压、NTC、容差和标定资料不全 | 误报或漏报开短路 | 原理图、量产标定和温度范围 | 使用宽松物理范围+连续计数，板测后收敛 |
| Flash 容量/MAC 区 | SDK 支持多容量，当前硬件 MID 未读取 | 分区误判可能破坏数据/OTA | 实物 MID、量产配置 | 自检只覆盖当前镜像，构建检查应用槽上限 |
| OTA 掉电与回滚 | Bootloader/Boot ROM 行为未在样板验证 | 可能反复启动或使用旧镜像 | OTA 规范与掉电测试 | 两套 CRC；未验证前不宣称安全回滚 |
| deep-retention | 当前宏为 0 | 将来启用时保留数据/输出路径未证实 | 目标低功耗配置和板测 | 预留重新自检入口；启用前强制完整验证 |
| 检测时间/电流/BLE | 当前环境无实物、示波器、BLE 链路 | 不能证明实时性和功耗指标 | 样板与测试设备 | 分块调度；所有实际值保持“未执行” |
| 标准符合性 | 缺少认证实验室评审和完整硬件安全分析 | 不能声称 IEC 合规/认证 | 独立 V&V、FMEDA/风险分析、实验室测试 | 仅称“认证准备框架/参考 Class B 思路” |
