# 性能与实时性记录

## 已测静态增量

最终生产构建：text 91,960 B、data 4,524 B、bss 5,824 B、总计 102,308 B；最终 BIN 96,580 B，Manifest 偏移 `0x1764C`。应用槽上限 `0x1F000`，BIN 尚余 30,396 B。以上是工具链静态结果，不是运行时间或功耗数据。
