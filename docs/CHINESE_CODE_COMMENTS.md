# 应用层中文注释覆盖与阅读约定

2026-10-06，在主开发分支 `codex-bms-monorepo` 完成。比较基线为
`2fc2d2037074f2ff711658f51725f0b5ad8a48ee`。范围是 `bms/` 下全部 115 个 C/H 文件，

## 覆盖范围

- 813 处函数定义、389 处函数声明均有紧邻的中文说明，共涉及 787 个函数名。
  计数包含内联函数、中断入口、回调、条件编译下的同名实现及重复声明。
- 所有文件均有中文功能说明；原有英文功能、字段和重要约束注释改为中文。
- 简要说明描述函数实际动作；重要注释保留保护恢复、通信静默、时基回绕、
  输出授权、写后验证和掉电提交等约束。
- 区分请求值、实际量化值、驱动缓存与物理输出；区分 RAM 待保存状态和已经提交的 Flash 记录。
- 函数名、寄存器、协议字段、单位、代码示例及厂商版权/许可证保留原文。
  SDK Vendor 源码不在本次修改范围。

## 在 VS Code 中阅读

普通说明注释包含缩进后的显示宽度不超过约 88 列；中文字符按两列、Tab 按四列计算。
长约束拆为多行块注释，保留原因、条件和失败后的行为，不通过删减约束缩短文字。
长 GATT 属性表后面的说明移到对应条目上一行，使注释本身可以直接阅读。
厂商许可证/装饰性边框和注释中的原始代码示例不受此宽度约定约束。

后续新增函数应在定义前写简要中文说明；公共接口同时在声明处说明。
注释解释职责、单位、所有者或约束，不逐句翻译函数体。复杂函数可以在关键阶段另写局部约束，
避免把整段调用流程挤到一个长行里。
