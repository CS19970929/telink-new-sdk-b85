# 电芯采样线断线检测：原厂调研与双后端方案

后续实施遵循用户已确认的“检测过程不关 MOS，真实故障仍保护关断”，见 [当前实施及监控说明](OPENWIRE_MONITOR.md)。本报告下文保留固定旧源码基线和当时候选方案，不代表后续实现或实板验收结论。

日期：2026-10-08。源码基线：`4faf0d4374de70bbbdd6c3e48b672084639ce42f`，分支 `codex-bms-monorepo`。工作树已有 UART、产品身份/参数等未提交修改；本报告核对当前工作树，不把它称为干净发布版本。

本次完成原厂资料调查、生产调用链和异常路径审查。**只新增研究文档和导航，不修改固件、上位机、参数或板子；未执行编译、测试、BIN 生成或 OTA。** 下文区分当前事实、工程建议和待实板确认项。DVC 的准确器件后缀/装配、SH 硅修订及板级条件仍按 [AFE 资料指南](AFE_REFERENCE_GUIDE.md) 和 [硬件验证清单](HARDWARE_VALIDATION.md) 确认。

## 1. 目的与必要性

这里的断线是电池到 AFE 的电压采样线开路，不是 RS485/BLE 断连，也不是 MCU 到 AFE 的 SPI/I2C 失联。

采样线断开后，输入滤波电容可能继续保持电压；只判断单体过压/欠压，可能暂时看见合理的旧电压。主动检测给输入施加已知激励，让悬空节点产生可辨别响应。因此它用于确认电压测量链可信度，避免基于错误读数继续充放电或均衡，并保留故障位置用于维修。[TI TRM，§5.3.24 p51](https://www.ti.com/lit/ug/sluuby2b/sluuby2b.pdf)

工程结论：量产应保留经过验证的断线诊断；开发时可暂时限制主动检测范围，但普通 OV/UV 不能视为等效替代。**周期检测不等于周期关闭主回路，检测进行中也不等于已经确认断线。** 检查周期、确认时延和保护动作要由产品允许的测量失效时间确定，没有适用于所有 BMS 的固定五分钟策略。

## 2. 行业原厂实现

| 原厂案例 | 检测方式 | 对本项目的启示 |
|---|---|---|
| TI BQ76952，TRM Rev.B | 典型 55 µA 下拉，激励时间默认 3 ms，检查间隔默认 5 s；节点逐渐放电后通过 CUV/COV、SUV/SOV 响应。调度避开正在测量的输入，SLEEP 仍可检查。 | 检查间隔不是最大故障确认时间；保护使能和阈值也影响检测。不能照抄其 5 s、阈值或 PF 策略。 |
| ADI LTC6811，Rev.C | `ADOW` 提供 ±100 µA，分别进行拉高/拉低转换并比较差值；底端和顶端使用独立判据。输入电容增大时需要更多转换。 | 重复转换可能是 RC 建立要求，不一定是故障去抖；端点与中间通道不能机械套用同一判据。 |
| ADI ADBMS6830B，Rev.0 | 奇偶分开开启差分激励，避免相邻输入形成分压掩盖断线；S-ADC 检测时 C-ADC 能继续正常测量。推荐诊断流程暂停均衡。 | 正常采样和诊断采样可以独立，但这是芯片专有能力，不能默认 DVC/SH 也具备。文中的 `DCP` / discharge 指均衡放电，不是电池主回路 DSG MOS。 |

来源：[TI TRM §5.3.24 p51、§13.3.8.1 p170](https://www.ti.com/lit/ug/sluuby2b/sluuby2b.pdf)、[LTC6811 p34、p61、p73](https://www.analog.com/media/en/technical-documentation/data-sheets/ltc6811-1-6811-2.pdf)、[ADBMS6830B p24–25、p30](https://www.analog.com/media/en/technical-documentation/data-sheets/adbms6830b.pdf)。这些代表案例不能作为全行业统计；已核对流程没有建立“所有 AFE 检测前必须关闭主回路 MOS”的共同前提。

覆盖边界同样要明确：底端、顶端和连续多根断线可能需要特殊诊断；发现测量链异常，不等于精确定位每根线。高阻接触、漏电和外部钳位也会改变响应，本次没有取得适用于 DVC/SH 的通用高阻判定阈值。[TI SDAA369 §2.2/2.3 p3](https://www.ti.com/lit/an/sdaa369/sdaa369.pdf)、[ADI 开线实验文章，端点与多根断线章节](https://www.analog.com/en/resources/technical-articles/deeper-look-open-wire-detection.html)

## 3. 两种现用 AFE 的依据与限制

### DVC1124-2

- [数据手册 V1.1，PDF p15](../references/afe/AFE_完整开发参考库_20261005/sources/DVC1124-2数据手册_V1.1.pdf)：C1…C24 集成 100 µA 下拉电流源，同时启动，约 1 s 后自动关闭。C0/供电参考端不属于这 24 个激励输入；端点覆盖需要结合实际接线确认。
- [参考手册 V1.2，PDF p22](../references/afe/AFE_完整开发参考库_20261005/sources/DVC1124-2参考手册_V1.2.pdf)：`CP_CTRL.COW` 启动检测，约 1 s 自清。该寄存器同时包含电荷泵配置，修改 COW 必须保留其他位。
- 当前驱动等待 200 ms，要求启动后的新 VADC 样本，并检查 COW 仍有效，然后取诊断电压、关闭 COW。200 ms 是当前软件选择，不是对所有板级 RC 的原厂保证。
- 当前后端用 `cell_mv == 0` 生成结果掩码。它是当前实现判据；不能仅据此声称所有断线和高阻都能检出。应保留原始诊断码，并验证噪声、量化、RC、连续断线和未用输入短接的影响。
- 上述断线说明没有列出主回路 MOS 必须关闭的步骤；也没有给本项目板子提供可直接签核的带载测试保证。

### SH3673510

依据 [SH36735XX CV1.0A 原 PDF](../references/afe/AFE_完整开发参考库_20261005/sources/SH36735XX%20CV1.0A.pdf)：

- p16 §7.7：使能 `OWD_EN`，触发 `OWD_TRG`，完成后检查 `OWD_FLG`，读取 `OWD_IND` 和 `OWDH/M/L`；需要收集两种奇偶阶段，才能构成完整一轮。
- p35：`OWV = code × 160 mV + 160 mV`。当前公共产品默认 code=5，即 960 mV。这是检测阈值，不是正常欠压阈值；本轮未读取板上有效寄存器值。
- p40–41：`OWD_FLG` 读后清除；只能由后端负责读取和分发完成证据，不能让上位机诊断或另一个任务抢读。
- p44：结果表示检测时序中对应 CELL 电压低于 OWV。单次命中不能排除真实低电压等其他原因，应用层应表达“采样链异常候选”，保留上下文供确认。
- **原文冲突**：p16 把 `OWD_IND=1` 与 `0x000AAAAA` 配对，但 p44 定义 OWD1 在 bit0。若按电芯编号奇偶理解，这两个描述不一致；当前源码沿用 p16 示例。资料更正层已登记此冲突，不能擅自交换掩码，也不能忽略它。必须记录两阶段完整 raw mask，并逐路断线确认当前实装芯片的位映射。
- p16 的检测控制示例没有要求先关闭主回路 MOS；检测是否改变正常 CELL 寄存器、是否触发硬件 OV/UV、实际转换时长和带载适用范围，仍需厂家澄清及板级验证。

## 5. 推荐应用层方案

保留现有 `feature → guard → 编译选定 backend` 边界，不引入新的 manager、运行时 ops 表或事件总线。公共层统一调度和故障语义，硬件激励与结果解释仍在后端。

### 5.1 分开检测调度与输出保护

建议产品编译策略只表达三个值：开发停用主动检测、仅在输出本已禁止的窗口检测、经过板级批准的在线检测。不要把它混入 AFE 硬件保护 profile 或持久参数布局。

- 启动自检：参数和 AFE 配置已验证、MOS 本来保持关闭时做有界检测；检测完成、激励已清除并取得正常新样本后，才进入原输出资格流程。不能通过重启清 RAM 故障直接绕过自检。
- 运行检查：在线能力未验证时，不为健康周期检查主动制造 MOS 脉冲；允许延期但必须报告最近成功年龄、延期原因和覆盖超期。若产品要求的最大诊断间隔无法满足，则该策略不具备量产覆盖条件；需要在线方案或产品明确的超期处置，不能无限等待。
- 已验证在线模式：停止并确认均衡，按照后端资格触发检测；仅“运行中”不自动新增 MOS 阻断。温度、电流、短路、通信、配置和真正测量异常仍有各自门禁。硬件保护不能为了使检测不关 MOS 而被临时屏蔽。
- 无论何种模式，都不能用报告零电流、MOS 关闭或零电流恢复来证明负载已移除。

### 5.2 结果和故障语义

现有 `IDLE/BUSY/READY/ERROR` 接口可以保留。扩充内部结果的覆盖信息及错误原因，并添加一个明确、可验证的停止/清理入口；不必新建大框架。

| 语义 | 最低证据 | 建议处理 |
|---|---|---|
| 检测进行中 | 已成功触发，截止时间未到 | 按产品检测模式仲裁，暂停均衡；单独记录开始/阶段，不能称为确认断线。 |
| 有效健康 | 全部有效通道完成、结果无异常、激励清理成功 | 更新最近成功时间；退出后仍取得正常新帧，才恢复资格。 |
| 测量链异常候选 | 一轮有效诊断命中，或正常测量已严重不可信 | 暂时阻断需要可信单体电压的输出及均衡，再作有界确认。不能为了去抖继续允许危险充放电。 |
| 确认故障 | 合格的重复完整诊断与有效通道映射；必要时结合正常采样/独立总压 | 锁存故障和原始证据，持续阻断输出；与真实欠压、AFE 通信失败分别记录。确认轮数由试验确定，不称行业标准。 |
| 检测失败/超时 | 启动、读取、完成覆盖或清理失败 | 记录具体失败原因，固定退避；不能置健康，也不能伪装成确认断线。清理未验证时保持输出禁止，需完整重初始化恢复。 |

恢复候选方案：两轮完整健康诊断、激励停止验证，再由现有 guard 确认三次正常新样本；两轮是待验证的产品建议。通信失效、配置失败和其他保护未恢复时，健康诊断不能直接打开 MOS。短暂正常电压、零电流、关 MOS 后的读数，均不能独立解除断线锁存。

| 契约 | DVC1124-2 | SH3673510 |
|---|---|---|
| 激励/完成 | COW，新 VADC 代次及有效窗口；200 ms 建立时间需按板级 RC 验证 | OWD_EN/TRG；FLAG3 由后端独占，收齐两阶段 |
| 结果 | 保留原始诊断电压及时间，不从旧缓存或激励后的普通帧判健康 | 保留每阶段 OWD_IND、完整 raw OWD 和时间，不先丢弃尚未核实的奇偶位 |
| 通道范围 | 按实际 profile 接线映射有效串位，C0/顶端另列覆盖 | 按产品有效串数和逐路验证后的位映射；D013 不支持均衡不等于不需要断线检测 |
| 截止/停止 | 单调 tick 截止，必须在 COW 有效期内拿到结果；退出明确清 COW 并核对稳定配置 | 两阶段各有截止和整轮上限；退出清 OWD_EN，清理读回失败不能返回健康 |
| 普通采样 | 激励帧不能覆盖“正常电压”缓存；影响到的 SW 电压滤波只暂停，不能清已有故障或增加恢复计数 | 是否隔离普通 CELL 帧由手册澄清/波形验证决定；未证明普通转换正常时同样标诊断质量 |

总截止/退避应按单调时间和无符号差值处理 tick 回绕；失联/低功耗导致服务停止也不能让检测无限挂起。通信 watchdog 静默期间禁止为清理再访问 AFE；先保持本地禁止，通信恢复后完整清理/重配，再取得原三帧资格。待检测和检测超期不能新增低功耗入口或绕过原休眠门禁。

SOC、OCV、min/max、正常电压保护、均衡和显示均需区分正常帧与诊断帧。有限时间内可保留最后正常值并标记年龄/质量；超过批准的新鲜度上限应进入测量失效处理，不能用旧值维持输出。未受影响的电流和温度保护继续运行。独立总压与单体和比较只能辅助诊断，先核对它们确实来自不同测量路径、并考虑动态负载误差。

## 6. 监控与量产边界

上位机建议分别显示：未启用、等待条件、检测中、正常、测量链异常、确认断线、诊断失败、覆盖超期。记录触发来源、序号、单调时间/持续时间、正常样本年龄、原始结果、有效覆盖、候选/确认掩码、停止结果及 MOS 请求/命令/AFE 状态。新增能力若实施，使用独立版本的只读诊断扩展；保留旧地址和 `DIAG_BLOCK_OPENWIRE` 含义，不直接改变旧协议。

MOS 历史应将“计划检测隔离”“确认测量链故障”“检测失败隔离”分开解释。现有轮询和有限 RAM 历史不能保证记录所有硬件瞬态；保留缺失、覆盖计数和重启标识，不能把没记录到当作没发生。量产可保留小型状态/故障计数，详细 trace/高频日志仍按 [运行日志规则](RUNTIME_DEBUG_LOG.md) 关闭；Flash 只通过现有受控事件策略保存关键故障，不能每个检测阶段擦写。

本方案不会触及 D011 PB5 fuse 安全电平、61001 未用串位约定、CFG2/Flash schema、OTA/APP 边界和已有通信参数。开发停用主动检测会减少诊断覆盖；量产长期删除它不是本报告的推荐方案。

## 7. 实施顺序与验收

1. 先补总超时、停止/读回、失败固定退避、两阶段覆盖和原始结果记录；拆分主动检测与确认故障原因。当前固件暂不直接取消 MOS 门禁。
2. 先在 MOS 原本关闭的窗口验证 DVC 和 SH 检测行为。SH 逐路确认奇偶映射；DVC 确认建立时间和诊断窗口。
3. 分产品评估在线检测：健康输入下记录 MOS Gate/Vgs 和主回路电流、普通 ADC、硬件保护标志；证明没有检测引起的健康关断或保护盲区后，才启用在线模式。
