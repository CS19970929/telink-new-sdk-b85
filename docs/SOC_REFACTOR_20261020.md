## 2. 设计与状态所有者

`bms_soc.c`直接维护内部电量、静置/端点资格和显示节拍；不增加Manager、事件总线或通用状态机框架。AFE后端独占寄存器激励与清理。应用只填样本并转交“需要新电压检查”的请求。State只接收显式快照，不能自行改SOC。

| 对象 | 单位/含义 | 修改入口 |
|---|---|---|
| `remaining_capacity_as10` | As×10，高精度剩余电荷 | 有效电流积分、可靠满空端点、普通OCV向下、人工SOC、容量基准换算 |
| `effective_capacity_as10` | 名义容量×循环SOH | 初始化、容量或循环更新 |
| `soc_estimate_percent` | 内部电量比例向下取整 | 从高精度电量派生 |
| `g_bms_report.soc.soc_percent` | 显示SOC | 冷启动及人工SOC立即同步；自动积分/校准按5秒步进 |
| `full_confirmed/full_basis` | 100%显示许可及配置依据，不单独证明电压判满 | 电压满电或人工100%授予；资格失效清除；State原子持久化 |
| OCV/端点计时及窗口 | 运行期资格 | 当前连续有效观测；不跨未知休眠或重启补算 |

SOC定义为参考条件下剩余电荷比例，不是某一放电倍率或温度下还能释放的能量比例。整套SOC不计算温度补偿，不设温度校准门禁；既有真实温度保护独立生效。

## 3. 安时积分、容量与循环

积分使用 `I_ma * elapsed_ms / 100000` 转成As×10，正值放电扣除，负值充电增加。使用第12节的有界32位拆分运算，带符号余数跨零流和方向变化保留，充电电荷效率100%。到0/满容量钳位并清除向边界外继续积累的余数，避免反向电流被“饱和积压”抵消。

- 所有有效实测电流均参与，包括±199、±200mA。方向资格和OCV小电流资格独立，不是积分死区。
- 沿用最新有效电流的矩形积分、毫秒无符号差；首帧仅建基准，重复时间不推进，≤400ms接受，>400ms不补盲区。无效帧/间隙撤销静置、端点确认及旧方向证据。
- 电压不可信、温度异常或真实电流保护位存在，不单独抹掉仍有效的电流输入。AFE/应用认定整帧无效时才停止该区间积分。
- 改普通曲线不从整数SOC重建电量，积分小数余量保留；容量/SOH改变按旧高精度电量占比换算到新有效容量。
- 不新增自放电、自耗、低流补偿或容量学习。未测得的休眠电量不凭空估计。
- 循环继续按真实积分导致的内部整数SOC下降累计；100个百分点为一等效循环，计数饱和65535。校准跳变不计放电循环。该旧口径有整数边界与浅往返敏感性，本轮未替换成吞吐量算法。
- SOH沿用0～80次100%、至500次降到90%、至800次降到80%的原整数经验公式，不是容量实测。

满电要求最高单体达到门限、最低不低于门限减裕量、压差合格、可靠充电过程、持续60秒和新电压检查。无尾流判据；3500/3300mV组合按用户选择允许LFP判满，不能将这个业务端点宣称为每串充分化学充满。

空电要求可靠放电、可信电压、最低过线、压差≤300mV、持续5秒和新电压检查。删除静置快速清零以及旧12/6/3/1多级末段拉低。端点确认后内部立即同步0/满容量，显示仍受5秒限制。

真实三级单体过压仍必须满足整包满电电压/压差和充电方向证据才补充满电，孤立高串不代表整包满。真实三级单体/总压欠压要求当前电压仍达到相应软件动作阈值、无可靠充电、且新电压检查通过；同一欠压事件只消费一次。未恢复UV锁存不能反复清掉后来充入的电量。保护/恢复和SOC端点各有所有者，不因SOC等待诊断或显示而延迟MOS动作。

“保护前显示100%/0%”是正常已验证工况目标，不是任何异常工况保证。显示差20个百分点就至少需100秒；突然大流压降/真实异常保护必须先执行。普通端点还会增加一次有界诊断及正常转换恢复时间，因此5秒空电并不等于墙钟恰好5秒完成。本轮未修改任何产品软件/AFE保护值。

## 5. 普通OCV的具体过程

1. 所有配置串必须存在且有效，不接收0/61001等无效槽位；重算min/max/delta必须与样本一致。按有效配置串算算术平均，不沿用旧的最低电压加权公式。
2. 电流幅值≤200mA、无电流/包压故障、无均衡，全部电压在profile工作范围内；LFP逐串通过平台禁区检查。任何一串在禁区，均值再低也不能绕过。
3. 连续合格60分钟；按真实时间加权统计每串一分均值，保留15项环形窗口。每串max−min≤5mV，同时当前瞬时电压不能偏离该窗口边界超过5mV，避免最后一个未完成分钟的突变借用旧均值。
4. 用平均电压查线性分段曲线，SOC插值向上取整后加模型带宽并钳位100%，得到允许上界。无额外2个百分点触发门槛，也不主动纠正偏低值。
5. 内部高于上界时，累计30分钟合格修正时间，随后请求一次新采样线检查。成功并重新检查当前候选条件后，扣除最多满容量的1%；末步不越过上界，非整除容量向下取整。
6. 每次动作清空30分钟修正计时，因此60分钟静置刚合格不会立即扣1%；首次约90分钟加一次诊断时间。资格丢失即停止/重新取得，不能攒积分额度然后一次补扣。
7. 不再有每次静置5个百分点预算、5%净电量重置或其持久化状态。保持合格可持续慢修正，重启后重新取得静置和30分钟资格。

主动诊断期间忽略激励电压并暂停电压计时，电流仍有效积分；电流活动撤销静置。停止激励后收齐正常转换，再消费一次结果；这段未知电压区间不填进一分钟统计。长间隔/失败/候选消失不保留待用证明。

LFP这张曲线在>3400mV一侧加7个百分点后上界为100%，所以“只向下＋宽禁区”的第一版实际主要在低压翼校正；不能承诺长期平台区静置能自动消除漂移。它优先避免平台区误校，低估由充电末段处理。这是已选策略的可观测性取舍。

## 6. 默认曲线来源与局限

LFP候选取国轩 `IFP72175207-314Ah` 产品规格书（QGX***-2024，修订页标QGX034-2024）A.3，印刷第19页、公开PDF第19页的25℃列。原件由分销站镜像托管：[原厂规格书PDF](https://www.gobelpower.com/download/files/Gotion-314Ah-LiFePO4-Cell-Specification.pdf)。公开文件只有21页而页眉写26页，编号含占位符，须在量产签核前取得可追溯的厂家受控版；不称为所有LFP的通用标定。

           3288:35,3291:55,3294:60,3315:65,3328:75,3330:95,3445:100

14点保留LFP低压翼和平台两端，删除原表重复电压/中间点以满足旧协议最多15点、电压严格递增。原表70%和75%均3328mV，压缩采用75%节点；40～50%、80～90%平台点被省略。平台禁校避免将压缩结果直接用于平台纠偏。7/5个百分点是工程保护带，不保证覆盖温度、滞回、老化、电芯型号差异及采样误差；本轮按用户要求没有温度补偿。

NMC保留既有13点工程对照，没有新增“所有4.20V三元电芯均适用”的验证结论。默认表、端点和静置参数必须用目标包实测确认后再发布。

## 7. 采样线检查与硬件边界

总线成功、范围正常、静置稳定均不能证明采样线完好。每次端点和每次OCV扣减前都需要一轮新后端检查，不永久信任开机一次结果。不改变主回路MOS意图，不增加周期关MOS流程。

原资料在 `references/afe/AFE_完整开发参考库_20261005/sources/`；固定审查入口和版本索引见 [AFE资料指南](AFE_REFERENCE_GUIDE.md)。

| 后端 | 原件依据 | 实现 |
|---|---|---|
| DVC1124-2 | DS V1.1原PDF15页；RM V1.2原PDF22页，CP_CTRL 0x6D/COW bit2 | 停均衡后使能100µA下拉；600～900ms内取新的VADC且COW仍有效；配置串诊断电压2000～5000mV才作为候选通过；显式清COW，再等两次正常VADC；失败不校准 |
| SH36735xx | CV1.0A原PDF16/32/40/44页，SCONF3 0x42、FLAG3 0x5A、OWD 0x97～0x99 | 后端独占读清FLAG3，收齐两种IND，所有配置串异常位取并集；不按存在矛盾的奇偶示例过滤；停止OWD后等两次正常VADC |

SH触发阶段最多2秒/4次完成尝试，正常转换恢复最多2秒；DVC取样超时拒绝，正常恢复最多2秒；失败重试退避5秒。均衡在检查全过程保持关闭，恢复后重新积累原均衡可信样本。SH负载检测RMW保留OWD_EN，不重复触发自清TRG。

诊断只给SOC一个保守资格；不新增自动排除坏串、修改保护阈值、清保护锁存或全局wire故障策略。通信失败走原guard，休眠清理只尝试一次，不因此拒绝保护性电源动作。

**未验证项**：DVC的600ms和2000mV不是厂家保证覆盖所有RC/高阻/底顶线故障的阈值；SH双相异常位及IND时序也未实板验证。独立硬件保护在主动激励时的行为、转换流水、板级RC、共模、相邻/多根断线必须量测。源码和寄存器替身只能证明拒绝路径，不能证明所有断线均已识别；当前不得宣称“异常电压绝不会误校准”的整板保证。

## 8. 判满资格、显示和重启

- 电压满电端点授予100%显示许可、记录配置basis；人工设置100%作为用户明确选择的例外，也授予同一显示许可。该标记不再单独证明发生过电压判满，不增加新的来源标记或存储字段。人工设置0～99%、容量/类型/满电规则改变、空电端点或高精度SOC<99%撤销许可。普通曲线微调不无故改写内部电量。
- basis关联policy版本、chemistry、名义容量、满电阈值/裕量/压差、60秒和配置串数；不把Config提交和State写入假设成跨域原子事务。重启按当前Config匹配，不匹配即无资格。
- 无资格且内部100%时目标99%，内部电量照保留。当前显示100%失去资格也只在下一合法5秒步进退出，不执行更快跳变。
- 冷启动恢复有效存储整数SOC；SOC100且有效匹配许可才从100显示，许可可来自电压满电或本版人工100%；否则内部100、初始显示99。旧State没有许可，不能仅由旧100授予许可。
- 运行期自动积分、满空端点、OCV校准和容量变化的显示统一5秒最多1个百分点。人工设置SOC成功后，内部电量和显示立即同步到指定的0～100%，清除未完成的显示步进；先通过`bms_soc_manual_state_snapshot()`构造SOC/许可/basis候选，State完整提交成功后才调用`set_soc_param()`发布。保存失败不改变内部电量和显示；人工100%不等待后一秒任务补存许可。不持久化显示追赶进度，冷启动不延续其余秒数。
- 低SOC告警使用内部估算，不等平滑显示；真实保护独立。所有容量报告由内部电量生成，不从display反算。

## 9. State schema 5兼容（用户选择10A）

分区、擦除/编程粒度、Config/schema4、Event/schema4不变。State标识 `ST5 + product ID`，schema5，payload32字节：原0～11字节SOC/dsg/cycle，原12～23字节OTA六word标记保持位置，24～27字节资格，28～31字节basis。记录总槽64字节，每4KiB扇区64条，8扇区512条。

启动先查ST5；无有效ST5且非I/O错误时，仅扫描同产品ST4/schema4/24字节。保留SOC、dsg、cycle及OTA标记，资格置0；第一条ST5写到旧最新记录的另一扇区。底层失败换扇区也保护旧最新扇区，新CRC和最终commit成功前不覆盖旧权威记录。空白才建默认；未知旧格式、产品不符或坏数据不作为默认覆盖。

State常规60秒检查点、失败5秒退避；资格变化在下一次一秒任务保存整个组合，无变化不写。保存失败保留最后成功缓存；首次迁移失败保留已验证导入值供运行读取，并继续报告存储失败，不退成60%默认；后续重试保留写游标及三次失败上限，不反复重扫/擦同一目标扇区。强制休眠尽力保存一次、失败不拒睡。

不逐笔持久化As×10或余数，仍可能丢失最后检查点窗口及不足1%的电量。新资格的State持久化失败时突断电，冷启动只能按旧已提交组合恢复，这不是跨掉电强实时保证。

ST4旧固件不懂ST5，直接降级可能读到旧检查点，轮换后甚至找不到有效State。回退需兼容ST5的维护版本或显式恢复/重新设置SOC流程；不能承诺任意旧固件直接保参降级。普通SOC组更新与SOC_STATE重置独立，迁移本身不消耗SOC_STATE更新ID。

## 10. 上位机、协议与参数治理

- 客户版不开放SOC算法散参数；既有人工SOC服务入口保留，100%操作说明其会立即显示并保存100%，属于人工指定，不代表已经通过电压判满。
- 内部版改成“读设备 → 选择LFP/NMC候选或导入完整JSON → 对比来源/端点/曲线 → 确认 → 分段暂存/完整提交/读回核对”。导出始终重新读设备，备份不假称型号已验证。
