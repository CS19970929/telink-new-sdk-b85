## 2. 参数从哪来（优先级）

1. **编译默认值**：D008 为 `d008_protection_config.h`；D011/D013/D014 的软件保护、AFE 硬件保护、SOC/OCV、均衡/加热、休眠与容量默认分别保存在各产品 `dXXX_protection_config.h`；仅范围检查共用 `sh3673510_parameter_checks.h`。
   电压类默认按 `BMS_PRODUCT_CHEMISTRY` 选 LFP/NMC 表（`*_FOR(c)` 宏）。
2. **持久配置**：Config journal（schema 4，414 B）中的软件保护、AFE requested profile、
   容量/身份、SOC 曲线、四项休眠、业务许可、校准/SN/BLE 后缀、OTA 标记。
   启动只有校验并提交成功后才取得安全配置资格。
3. **AFE 硬件保护**：持久 profile 是 **35-word**；启动应用后回读 requested 与 effective，
   不一致或写入失败保持输出禁止。
4. **OTA 更新组**：`sw / afe / business / soc / soc_state / factory_reset`，一次性执行，
   标识编入 BIN；保留模式不覆盖已有标识。

## 3. 硬件保护（AFE 自主动作）

硬件保护由芯片自己判定并在配置的延时后关闭 MOS，**与软件保护独立**；软件只负责写配置、
回读验证和"何时允许清除锁存"。

### 3.1 D008 / DVC1124

| 项 | 值（LFP / NMC） | 延时 | 恢复条件 |
|---|---|---|---|
| COV | 3750 / 4200 mV | 1000 ms | 3500 / 4100 mV，稳定 1000 ms |
| CUV | 2500 / 3000 mV | 1000 ms | 2800 / 3100 mV，稳定 1000 ms |
| OCD1 | 80 A | 100 ms | ≤10 A，稳定（恢复窗口由 profile 决定） |
| OCD2 | 100 A | 100 ms | 同上 |
| OCC1 | 60 A | 100 ms | ≤10 A，稳定 |
| OCC2 | 80 A | 100 ms | 同上 |
| SCD | 40 mV ≈ 200 A @200 µΩ | 256 µs | 锁存，需物理证据 + 回读 |

同时配置：DSG/CHG mask 策略、I2C watchdog 4 s、体二极管阈值、电流唤醒阈值、GP 模式、
CADC/CP/VADC。写配置是"安全基线 → 硬件保护参数 → 完整运行字段"三阶段，
**失败时保留已写入的基线**，不会整体回退成未保护状态。

## 4. 软件保护（MCU 三级）

三级统一算法：First/Second 只告警，Third 进入 CHG/DSG 阻断。

- **触发滤波**：越限样本累积，正常样本把计数减 1（漏积分去抖）。
- **恢复滤波**：连续满足恢复条件才解除；两者不是同一种滤波。
- **物理证据**：SC/OCD/OCC 在 Third 激活后，恢复必须满足负载/充电器移除或可靠反向电流，
  且需要新鲜采样；不能凭"关 MOS 后零电流"解除。
- **压差**：三级 `cell_delta_high` 同时阻断充电与放电；一二级只告警。
- **SOC Low**：20/10/5%，恢复 11%，只报告，不进阻断掩码。

### 4.2 阻断范围

- 充电阻断：单体/整包过压、充电过流、充电高/低温、MOS 过温、压差三级。
- 放电阻断：单体/整包欠压、放电过流、放电高/低温、MOS 过温、压差三级。
- 加热与均衡另有独立准入：加热要求温度需求、无放电电流、充电源在位、无硬故障；
  均衡要求电压可信（连续 1 s + 相邻帧跳变限制）、温度窗口、无放电、无硬故障、未等待 OFF 确认。

## 5. 恢复逻辑

### 5.1 软件保护

1. 激活后按 Recover 阈值和 Filter 时间连续确认；
2. 电流类（SC/OCD/OCC）还要 `负载/充电器移除` 或 `可靠反向电流` 证据；
3. 证据缺失只暂停该保护的恢复计时，不触发 AFE1，也不清已触发故障；
4. 通信恢复重初始化只清滤波计数，保留已确认故障和温度回差（`bms_sw_protection_init`）。

### 5.2 DVC 硬件锁存恢复

`dvc_clear_recovered_hw_latches()`：

- 必须本轮采样有效、profile 可读、且本轮有**新的 VADC/CC2 转换**（`voltage_fresh`/`current_fresh`）；
- COV/CUV 各自需要稳定窗口（profile 的 recover_ms，> 而非 ≥）；
- 轮询间隔超过 400 ms（休眠/调度空洞）会丢弃已累计的证据；
- 写清除后立即回读 ALARM；清除失败或回读失败上报 `io_failed`，锁存保持不变；
- SCD/OCC/OCD 另有"物理移除/反向电流"证据，不能只靠电压稳定。

### 5.3 SH 硬件标志恢复

9 个独立窗口（OV、UV、OCD1、OCD2、OCC、OTC、OTD、UTC、UTD），每个：

- 标志在 → 推进自己的样本计数；标志消失 → 清零；
- 达到 `ceil(恢复毫秒/200 ms)` → 置待清除位；电压/温度只用 VADC，电流只用 CADC；
- 清失败锁存 `s_flag_clear_failed`，下次采样直接失败，直到完整 `control_init`；
- **SC 单独处理**：清除后置 pending，必须再看到 SC=0 且（负载移除或真实充电）才解锁；
  任何失效都退回完整 LOADOFF 10 样本窗口；真实反向充电可立即发起清除。

### 5.4 输出恢复

guard 只有在"完整业务轮次成功 + 配置一致 + 完整测量 + 必要控制成功"后才撤销通信禁止；
总线静默期间（DVC 5 s / SH 35 s）任何路径不得访问 AFE。

## 6. 异常判定与处理

| 异常 | 判定 | 处理 |
|---|---|---|
| 单次读失败（CRC/超时/协议） | 后端返回 READ_ERROR/ERROR | 本轮测量不发布、不积分、不作恢复证据；不撤已运行 MOS；guard 记录 |
| 持续通信异常 | 连续 **1000 ms** | 确认 AFE1；尽力关闭输出；进入 watchdog 静默窗口 |
| 配置不一致 / 芯片复位标志 | SH RST1/RST2、DVC 写后回读不符 | 配置禁止，输出保持关闭，直到完整重配 + 验证 |
| E2P 错误（SH） | BSTATUS1.E2P | 立即 AFE1，禁止输出 |
| NTC 开路/短路 | 电阻越界或必需通道无效 | TEMP_BREAK 锁存（必需传感器）、停止加热/均衡；SH 启动 1.2 s 内不做温度资格 |
| 无效串位 | 通道无效 | 发 61001，不计入有效串数、min/max、SOC、保护 |
| 采样时间不连续 | 相邻轮询 > 400 ms | SOC 作废该区间；硬件恢复窗口清零 |
| 软件保护 | 三级滤波 | 置 fault 位、记录历史事件、阻断对应方向 |
| SC 锁存 | 硬件 SC 置位 | 锁存故障位，物理移除后才允许清；清后需下一帧确认 |
| 远程控制 | RAM 许可 0/1 | 许可只影响请求，不绕过保护、不请求休眠 |
| 输出仲裁失败 | 本轮任一必要事务失败 | 禁止同轮新开；已确认关闭和真实保护仍执行 |

**故障位合并顺序**：先 `bms_sw_protection_update`（清它拥有的位），再合并 AFE 硬件锁存位；
反序会把硬件锁存位清掉。

## 7. 休眠逻辑

### 7.1 四个入口

| 入口 | 触发 | 等待 |
|---|---|---|
| 低压下档 | 单体 < 2800 mV 持续 60 min | 到期即睡 |
| 低压上档 | 单体 < 3000 mV 且无可靠充电（电流 ≥ −200 mA）持续 24 h | 到期即睡 |
| AFE 异常 | AFE1 已确认，固定 **30 min** | 到期即睡 |
| 固定过放 | `cell_uvp` 或 `pack_uvp` 置位，持续 **180 s** | 恢复需电压回到 Recover 以上且有效 |

另外三条命令型入口：**0x1102 关机命令**（等应答空闲最多 500 ms）、**开关 OFF**（SH，
立即）、**ACC OFF**（D008，立即，保留 PC4 供电）。

多个条件同时满足时按"剩余时间最短"选择，同到期时后面的优先（AFE/过放覆盖低压）。

### 7.2 普通 Suspend 与保护性深睡

- **普通 Suspend**：`s_low_power_mode` 由"采样有效、无到期采样、|电流| < 200 mA、无 OTA、
  Flash 空闲、总线空闲、UART 就绪、无按键"决定；唤醒源保留 PAD 变化与 200 ms 采样定时器。
- **保护性深睡**：一旦提交就**锁存**，不再回到业务；只执行一次收尾（关输出、通知 AFE、
  需要时保存 State/Event、断 BLE、关广播、禁 Suspend）。
- D008：AFE 发 Shutdown 后拉低 `MCU_LDO`，MCU 断电；唤醒走完整启动。
- SH：尝试 AFE Sleep，关闭 CMNT_EN，强制 DeepSleep；入睡时开关 ON 才用 `DEEP_ANA_REG6` 存
  "开关唤醒标签 + INT_WK 电平"。随后单独 OFF 会在业务初始化前重新深睡，再 ON 或 INT_WK 改变才正常启动。
- SH 普通 Suspend 保留 200 ms 采样、BLE 调度、开关/INT_WK/UART PAD；DeepSleep 只保留开关/INT_WK，
  ALARM/RESET_OUT 当前不使用，仅启动时配置高阻并禁用唤醒。UART 不打断已提交的深睡。
  D008 的 ACC/断电恢复边界见 [休眠梳理](SLEEP_LOGIC_REVIEW.md)。

### 7.3 失败与边界

- AFE 休眠命令失败也照样执行 MCU 断电/深睡（不能因为 AFE 不响应就不睡）。
- OTA/Flash 会话中不追加保存，但同样不阻止深睡。
- 过放恢复要求"有效样本 + 电压回到恢复值"，通信恢复重初始化不能冒充电池恢复。

## 8. 电流怎么算

### 8.1 D008 / DVC1124

1. 读 CC2_H/CC2_M/CC2_L_FLAGS，拼成 **20 位补码**，符号扩展到 int32；
2. CC2 LSB = 0.3125 µV，按分流电阻换算：
   `raw_ma = cc2 × 625 / (Rsense_µΩ × 2)`（等价 `cc2 × 312.5 / Rsense`）；
   200 µΩ 时约 **1.5625 mA/LSB**；
3. 保存 `snapshot.raw_current_ma`（未校准），再应用工厂校准得到 `snapshot.current_ma`；
4. 0.1 A 报告：|I| ≤ 200 mA 视为不可信，报 0；否则 `a10 = |I|/100`（**向下取整**），
   上限 65535；正=放电，负=充电。

### 8.2 D011/D013/D014 / SH3673510

1. 只读 CADC（FLAG2 的 CADC 完成事件），得到 16 位有符号原始值；
2. 换算式（整数精确截断，避免 64 位库）：
   `mA = raw × 100000000 / (29127 × Rsense_µΩ)`，符号保留；
3. 公共方向约定是"正放电"，而 SH 原始方向相反，因此发布前取反：
   `raw_current_ma = -chip_ma`；
4. 应用同一套工厂校准（先减 offset，再乘 gain ppm）；
5. 0.1 A 报告：`a10 = (|I| + 50)/100`（**四舍五入**），上限 65535。

### 8.3 校准

`bms_config_calibrate_current()`：先减 `current_offset_ma`（饱和到 ±2147483647），
再乘 `current_gain_ppm/1e6`；用 32 步移位除法，不依赖 64 位运行库，结果饱和不溢出。
校准值不改变 `raw_current_ma`，诊断可对照。

> 观察到的差异（非缺陷结论）：DVC 报告有 200 mA 死区且向下取整，SH 无死区且四舍五入。
> 两者只影响 0.1 A 报告字段，保护、SOC、PM 用的都是校准后的 mA。

## 9. 未验证与边界
