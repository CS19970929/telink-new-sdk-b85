# D008 独立固件收敛记录

基线：`e3e9b87a8f72`。目标为简单、稳定、易调试的保护板。每轮独立提交，不改变硬件拓扑、保护优先级、协议地址、Flash 边界或发布签核。没有实板证据不得宣称量产通过。

## 第一轮：验证基线

基线 Actions run `45583600015`：36 组 host 中 2 组失败（SOC、Storage）；TC32 五种装配因容器缺少 python3 尚未启动链接。最新源码 LFP 默认 SOC100/SOC0 为 3550/2600 mV、默认容量 20 Ah；旧存储测试仍固定 3500/2850。更新默认值与字节序预期，保留故障注入及校验，失败输出进入 CI 日志。不得为取得 PASS 放宽安全测试。

## 第二轮：SOC 输入和积分

统一 SOC 零电流区为 ±200 mA；保留原始测量、真实失采及超过 400 ms 间隔的断开保护。连续有效的相邻应用轮次使用完整时间差，取消重复的上一转换年龄截尾。新增正负零区回归，并修复原显示追赶夹具，使测试确实存在一个百分点的内外 SOC 差值。此轮未改变硬件保护和满空确认。

## 第三轮：端点快速截断

充电保护边沿叠加最近有效方向、可信新电压和整组满端证据，不再强制预先累积候选时长。放电保护边沿及正常压差低压证据可确认空端，弱串仍需旧候选与线路检查；保护截断确认空端可直接显示 0%，普通端点保持平滑。新增四类正负控制场景，未更改硬件保护阈值。

## 第四轮：三组电压参数一致性

统一 SOC100/SOC0、启用的软件单体/总压三级阈值、启用的 AFE COV/CUV 组合校验。软件/AFE 候选在提交前拒绝冲突，AFE 事务在关 MOS 前拒绝冲突。新建或选更后配置必须一致；已有保参板如存在旧冲突，保留已验证的硬件/软件保护并报告 SOC_CAL，不扩大安全锁定。可先调整 SOC 再调整保护，或反向按合法中间组合修改。新增无 Flash、无 AFE 副作用的拒绝以及恢复合法组合的回归。

## 第五轮：可选存储域独立恢复与有限失败重试

保留 Config 安全门禁和三个地址域。State/Event 可读而无合法记录时，仅报告自身故障，重新估算/追加，不在启动时主动擦除；I/O 不确定继续禁止写。State 已知失败上限/未知提交后直接停止无效轮询；Event 连续三次真实事务失败后停止 Flash 重试，RAM 日志仍工作。增加损坏、I/O 失败、恢复追加和失败预算回归。未改变普通 5 min 检查点寿命合同；掉电精度与 Flash 页编程/时序仍需实板验证。

## 第六轮：AFE Guard 互斥状态与 MOS 仲裁收敛

总线 Active/Watchdog wait/Shutdown 由一个枚举持有，通信资格和配置门禁仍独立；请求合并为双方向掩码，均衡必要 I/O 失败及 OFF 确认用互斥状态表达。关断失败直接由仲裁入口记录，不再通过临时 closing_failed 跨函数传递。保留 1s 通信确认、4s 硬件 WDT、5s 静默、恢复次数、AUTO_DIODE、远程许可及配置回滚。增加主动 Shutdown 不可被普通恢复计时唤醒的回归。

## 第七轮：低功耗与均衡判定单一所有者

应用 Power 状态改为 RUN/Suspend 许可/保护关机/ACC 深睡互斥枚举。采样到期只由 app_sample_is_due 判断，删除重复的 volatile 指针传递；采样计时在唯一调用点结算。均衡准入直接使用完整阻断原因掩码，删除重复的第二组条件。保留电压检查关闭、温度回差、选串、通信唤醒和所有保护性关机门禁。未改变加热器供电合同（充电器拔除仍需硬件证据）。


## 第八轮：底层总线门禁与零点诊断

寄存器读、写统一在实际 I2C 事务之前查询 Guard 静默许可，防止调试、配置或恢复子路径绕过看门狗静默；正常启动及已授权恢复保持原顺序。CAMZ 检查失败发布既有 ADC 错误，成功后清除；不学习第二套软件 offset，不引入永久 MOS 锁定，不擅自提高零区。新增实际读写函数体的静默/放行回归以及启动结果回归。

## 第八轮补充：清理无消费点的宏

删除旧 OCV 曲线宏和未使用的四档 SOC 灯 GPIO 定义；实际算法 OCV、蓝灯驱动和板级安全输入保留。同步相关宏索引及 SOC 文档，避免误以为旧宏可改变运行行为。

## 实板验收边界

软件回归和 TC32 链接通过不替代实板验收。保留 BMS_PRODUCT_RELEASE_APPROVED=0，禁止未经签核生产发放。重点验证：不同装配 CAMZ 失败时真实零偏及短路/过流恢复、I2C 完全失联后的 4s 硬件看门狗动作、关机 MOS/均衡关闭与 PC4 供电时序、加热中拔充电器、电芯快速端点及带载弱串、Flash 擦写寿命与 5 min 检查点掉电误差、OTA 中断恢复。未引入新的硬件假设或擅自改变存储周期。
