# D008 宏配置与保护参数盘点

本次盘点以 `refactor/d008-production` 的工作区为准，装配为 16 串 LFP、20 Ah、DVC1124-2、等效 Rsense 250 µΩ。表格中是源码默认值和由源码推导的寄存器值。设备已保存的 Config 可覆盖默认值，现场值应从目标板读回。

[逐宏索引](D008_MACRO_INDEX.csv)是本次收敛前对 `bms/` 下 92 个 C/H 文件的盘点快照，已同步删除本轮清理的六项定义及两个产品头的行号。其他重构文件的行号、新增内部宏以当前源码为准。索引列出源文件、值、用途、配置窗口支持以及保留建议。预处理的条件分支分别列出，保护的 LFP/NMC 值位于同一 `*_FOR(c)` 定义内。供应商 SDK 原始宏、测试替身、界面样式和 Python 常量在各自源码维护。

## 哪些值值得在窗口配置

| 分类 | 当前入口 | 建议 |
|---|---|---|
| 串数、化学体系、容量、开发/生产、OTA 更新组 | Ctrl+Shift+B 主窗 | 保留。AFE 型号在本工程固定为 DVC1124-2，只需显示。固定 profile 和实际装配必须匹配。 |
| 客户/方案标签、等效 Rsense | 保护参数窗口的装配页 | 方案标签常用。Rsense 是装配值，作为工程配置保留，变更后重新核对电流标定及 OCP、SCD 的有效档位。 |
| 软件与硬件保护、加热、均衡、低压关机阈值/延时 | 保护参数窗口 | 保留，按保护项呈现单位及恢复关系。软件保护当前有一组表达式宏未被窗口解析，见下文。 |
| `SOC100` / `SOC0` | `bms_soc_defaults()` 和设备参数协议 | 建议加到源码参数窗口。工作区默认 3550/2600 mV，普通 OTA 保留已存值，需要覆盖时选 `soc`。 |

| 产线批准、GPIO 路由、AFE 运行固定字段、看门狗、Flash/OTA 地址、协议号、存储 schema | 各自所有者文件 | 保留并审查，适合只读呈现。寄存器地址、掩码、单位换算、包含保护等定义随实现维护。 |

## 软件保护当前默认

`D008_SW_*` 由 MCU 按一级/二级/三级阈值、恢复值和滤波时间执行。下表为当前 **LFP** 分支。总压按 `单串折算值 × 串数` 计算，16 串值已列出。滤波栏是配置值，软件判断按 200 ms 采样节拍运行。软件低 SOC 由 SOC 应用更新告警，电压保护的恢复还受实际测量及方向证据约束。

| 项目 | 一级 / 二级 / 三级 | 恢复 | 滤波 |
|---|---|---|---|
| 单体过压 | 3500 / 3600 / 3650 mV | 3550 mV | 1 s |
| 单体欠压 | 3000 / 2900 / 2500 mV | 2900 mV | 1 s |
| 整包过压 | 56.00 / 57.60 / 58.40 V | 56.00 V | 1 s |
| 整包欠压 | 48.00 / 48.00 / 40.00 V | 48.00 V | 1 s |
| 充电过流 | 30 / 35 / 40 A | 1 A | 100 ms |
| 放电过流 | 100 / 110 / 120 A | 1 A | 500 ms |
| 充电高温 | 40 / 50 / 55 °C | 40 °C | 1 s |
| 充电低温 | 5 / 3 / 0 °C | 3 °C | 1 s |
| 放电高温 | 50 / 60 / 65 °C | 50 °C | 1 s |
| 放电低温 | −10 / −15 / −20 °C | −10 °C | 1 s |
| 功率 MOS 高温 | 75 / 85 / 95 °C | 80 °C | 1 s |
| 单体压差 | 600 / 800 / 1000 mV | 800 mV | 1 s |
| 低 SOC | 20 / 10 / 5% | 11% | 1 s |

保护源配置在 `d008_protection_config.h`。窗口识别纯数字或指定形式的 LFP/NMC 条件式，当前会跳过 `(300)`、`(10)` 和 `((温度 + 40) * 10)` 形式的 21 项软件参数。可在源码保留公式，或写成等效数字字面值让窗口接管。表里每项的具体宏和窗口状态见逐宏索引。上位机在线软件保护从 `0x2100` 参数区读取与编辑。

## DVC1124-2 硬件保护当前默认

`DVC1124_SW_PROTECT_ENABLE`、`DVC1124_SW_TEMP_PROTECT_ENABLE`、`DVC1124_HW_PROTECT_ENABLE` 当前都是 1。硬件七组均开启。过压、欠压和过流的恢复值由 MCU 配合故障锁存参与恢复。硬件短路阈值是在分流器两端测到的压差。

| 项目 | 源码请求 | 芯片名义动作 | 恢复设置 | AFE 地址与默认写入 |
|---|---|---|---|---|
| COV 单体过压 | 3750 mV / 1000 ms | 3750 mV / 1000 ms | 3500 mV、1000 ms | `0x70/71 = CB/28` |
| CUV 单体欠压 | 2500 mV / 1000 ms | 2500 mV / 1000 ms | 2800 mV、1000 ms | `0x72/73 = 9C/48` |
| OCD1 放电过流 | 150 A / 100 ms | 150 A / 96 ms | 10 A，按恢复条件 | `0x59/5B = 96/0B` |
| OCD2 放电过流 | 300 A / 100 ms | 288 A / 100 ms | 同 OCD1 | `0x5E/60 = 51/18` |
| OCC1 充电过流 | 60 A / 100 ms | 60 A / 96 ms | 10 A，按恢复条件 | `0x5A/5C = 3C/0B` |
| OCC2 充电过流 | 80 A / 100 ms | 80 A / 100 ms | 同 OCC1 | `0x5F/61 = 44/18` |
| SCD 放电短路 | 150 mV（600 A）/ 256 µs | 150 mV（600 A）/ 249.92 µs | 按短路锁存及恢复条件 | `0x62/63 = 4F/20` |

OCD2/OCC2 表列有效配置字段，保留位按芯片读改写规则处理。电流与动作延时为按标称分流器和编码推导的名义值。寄存器编码依据 DVC1124-2 RM V1.2 第 18–24 页。Profile 构造及软件恢复路径分别见 `bms_afe_hw_profile.c` 和 `dvc1124_bms.c`。

## DVC1124-2 固定运行配置

| 项目 | 当前设置 |
|---|---|
| I²C 与启动 | PC0 SDA、PC1 SCL，100 kHz，8 位写地址 `0x40`（7 位地址 `0x20`）。PD7 接口使能高，等待 20 ms，施加 1 ms 线路唤醒脉冲，复位后等 300 ms。单次命令超时 5 ms，常规事务最多 3 次。 |
| 电芯及测量掩码 | 16 路有效，屏蔽 17–24，`0x6A..0x6C = FF 00 00`。保留 PACK、LOAD、芯片温度与 V1P8 测量，单体采用无符号码，CMM 为 0。 |
| CADC / VADC | 工作 CADC 开，CC1 工作 4 ms、睡眠唤醒档位 32 ms，CC2 256 ms。VADC 开、每个 CC2 同步一次、1.54 ms 档。 |
| NTC / MOS | GP1 加热电路、GP2/3 电池、GP4 功率 MOS；GP5/6 控制低侧 CHG/DSG，高侧驱动屏蔽。电荷泵 10 V，DSG 下拉强度编码 16，体二极管恢复压差 80 µV（名义 0.32 A）。 |
| 休眠唤醒与看门狗 | 3.3 V 在工作和芯片睡眠均开。AFE 定时唤醒、电流唤醒与 3.3 V 超时重启均关闭。I²C AFE 看门狗 4 s，超时影响 CHG/DSG 两路。MCU 侧通信故障确认 1 s、看门狗静默窗口 5 s。 |
| 其余固定字段与动作 | AFE 中断屏蔽 `0xFF`，核心过温关断关闭。启动有 CAMZ 检查，采样相隔 270 ms；它不写入第二套电流零点。失败报告现有 ADC 错误，成功清除。均衡位由 MCU 调度，芯片按有效期自动清除；关机命令由 MCU 在退出时发送。 |

固定运行配置的入口为 `dvc1124_product_defaults.h` 和 `DVC1124_ApplyProjectOperatingConfig()`。固件在 AFE 复位后应用。运行窗口中的寄存器浏览适合核对，不作为修改这组板级策略的入口。

固定配置写入目标以十六进制表示。`52=10`（DPC 字段）、`53=50`、`54=78`、`55=88`、`56=0F`（CC1 字段）、`65=00`、`66=02`、`6D=28`、`6E=C1`、`74=49`、`75=7F`、`76=00`（COTT 字段）、`77=C4`、`78=00`、`79=FF`。FET 命令、CAMZ、断线检查、告警和均衡这样的运行位随状态变化。

## 怎么改以及怎么生效

1. **修改源码默认。** Ctrl+Shift+B →「保护参数 / AFE 位配置」→ 参数表选择 LFP 或 NMC，修改 AFE 阈值、使能、延时、恢复值或软件保护。允许编辑的 AFE 寄存器位会反算到源参数宏。保存先改源码，构建之后才得到含新默认的镜像。
2. **更新已经有 Config 的板。** 普通 OTA 保参。让已有板采用软件或 AFE 新默认，分别选 `sw` 或 `afe` 并保存参数包标识。两档休眠的源码默认用于建立新 Config，已有板通过上位机休眠参数写入。`factory_reset` 会清空业务域，适合明确需要出厂初始化的设备。
3. **读取和修改已连接板。** 上位机的软件保护区读当前保存的 SW 参数，AFE 硬件保护区可读 `0x2500` 请求配置与 `0x2540` 实际寄存器量化回读。在线 AFE 修改走已有工程授权和完整 Profile 写入，固件应用并读回成功后再提交 Config。
