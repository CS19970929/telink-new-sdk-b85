## 换算规则

SH p37..38：OCD1 `(code+1)*5mV`，OCD2 `(code+1)*10mV`，OCC `(code+1)*1.375mV`；SC 是 **OCD2 原始感测电压档**乘 2/3/4/6，SCT 用原厂非等距 16 档表。OV/UV 是完整 10 位值乘 5mV，延时用各自枚举。电流换算使用精确分流器比例；D014 为 `2000/3 µΩ`。

DVC p18..20、p23..24：OC1 为 code×250µV（0 关闭），OC2 为 `(code+1)*4mV`，SCD 为 code×10mV；延时分别为 `(code+1)*8ms`、`(code+1)*4ms` 和 code×7.81µs。COV 是完整 12 位 code+500mV（0 关闭），CUV 是完整 12 位 code mV（0 关闭）。源码窗口跟随实际默认构造/限幅和驱动量化，显示“预计”，不把复位值当作当前值。

物理参数的 0.1A、整数 µs 等表示范围可能无法精确反解所有 raw 编码；遇到这种情况保持原值并说明原因。SH 温度阈值还依赖当前板 NTC 表。当前 GUI 不支持任意板级 B 值/引脚映射修改。
