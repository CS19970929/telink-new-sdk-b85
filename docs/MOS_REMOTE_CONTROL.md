# 充放电 MOS 独立远程许可

## 目标与边界

App 和 Windows 上位机可分别禁止或重新允许充电、放电 MOS。该功能只改变用户侧 RAM 许可，不发送休眠命令，不修改 Flash/OTA/参数布局，也不绕过软件保护、AFE hardware profile、通信静默、三次有效采样资格或产品功能门禁。

“允许”表示解除用户主动关闭条件，不表示强制输出。界面必须分别显示用户许可、产品请求和 AFE 报告；只有 AFE 报告有效时才能称为驱动状态，仍不能替代 Gate/Vgs 或负载通路实测。

## 状态所有权与调用链

`bms_afe_guard.c` 的 `s_remote_off_mask` 是唯一远程许可状态：bit0 关闭充电许可，bit1 关闭放电许可。`bms_afe_set_channel_allowed()` 每次只修改一个通道，再进入既有 `apply_requested()`；后者继续按以下顺序收紧输出：

1. 产品请求 `requested_charge_on/requested_discharge_on`；
2. 远程许可；
3. `output_enabled`、保护参数资格、升级状态、通信隔离与总线静默；
4. 产品功能方向门禁；
5. AFE backend 写入及回读。

显式关闭在 AFE 重初始化后保留，避免通信恢复过程在没有电流依据时意外重新允许；MCU reset/BSS 重建后恢复为两个通道均允许。重新允许失败时回滚到原关闭许可；禁止写入失败时保留 fail-safe 关闭意图并返回设备故障。许可发生变化后立即把旧 AFE 报告标为无效，等待后续真实回读。

远程单管关闭不得对抗同口反向导通。公共 guard 在每次完成的新鲜有效电流样本中执行以下安全释放：

- 充电 MOS 被远程关闭时，公共电流严格大于 `+200 mA`（放电）便清除充电关闭许可；
- 放电 MOS 被远程关闭时，公共电流严格小于 `-200 mA`（充电）便清除放电关闭许可；
- 等于 `±200 mA`、缓存等待、无效样本和零电流不作为方向依据；
- 最近一次新鲜样本仍表明反向电流时，新的对应关闭命令直接拒绝，任何 App、Windows 或其它 Modbus 客户端都不能保持危险的单管关闭；
- 自动清除只恢复用户许可，随后仍通过参数、通信、三次采样资格、软件保护、AFE hardware profile 和产品门禁；它不强制绕过保护开管。

SH36735XX CV1.0A 原 PDF 物理页 17 说明 `MOS_EN` 可按反向电流自主强制开启另一 MOS；物理页 22、28 分别给出管脚状态和 `BSTATUS1.CHG_FET/DSG_FET`。DVC1124-2 RM V1.2 原 PDF 物理页 7-8 定义 `R6.CHGF/DSGF` 为驱动输出报告。公共策略不再让用户关闭掩码覆盖已确认的反向电流安全释放；两种后端仍各自负责实际 MOS 仲裁、写入和回读。

## Modbus 窗口 v1

窗口为 holding register `[0x2F10, 0x2F18)`，word 大端。读取使用功能码 `0x03`。

| 地址 | 访问 | 内容 |
|---|---|---|
| `0x2F10` | R | magic `0x4D43` (`MC`) |
| `0x2F11` | R | version `1` |
| `0x2F12` | R/W | 充电用户许可，`0` 禁止，`1` 允许 |
| `0x2F13` | R/W | 放电用户许可，`0` 禁止，`1` 允许 |
| `0x2F14` | R | AFE 报告 bit0 充电、bit1 放电 |
| `0x2F15` | R | AFE 报告有效且采样已取得资格时为 `1` |
| `0x2F16` | R | guard 诊断位：输出授权/通信隔离/总线静默/故障锁存/采样资格 |
| `0x2F17` | R | 产品请求 bit0 充电、bit1 放电；未应用远程许可 |

功能码 `0x06` 只允许写 `0x2F12/0x2F13`，值只能是 `0/1`；其余地址只读。功能码 `0x10` 的单 word 请求沿用现有单写分派，多 word 写入拒绝。最近新鲜电流仍要求对应通道开启时，写 `0` 返回设备故障且许可保持为 `1`。广播地址 `0` 对整个窗口不执行任何副作用，避免多台设备同时切换 MOS。旧固件返回非法地址时客户端只禁用独立控制，不影响实时数据读取。

`DIAG_BLOCK_REMOTE=0x0800` 记录远程许可造成的通道阻断；既有原因位和历史布局保持不变。

## 验证边界

本轮按用户要求只修改和审查源码，未执行 host 回归、`sources --check`、目标链接、资源检查、Windows/Android 编译、实板切换、烧录或 OTA。新增 host 场景覆盖独立通道、重初始化保留、允许失败回滚、`±200 mA` 边界、`+201 mA` 放电自动释放充电许可、`-201 mA` 充电自动释放放电许可、同向电流不释放、反向电流期间拒绝重新关闭，以及协议读写、只读地址、值域和广播无副作用；本轮未运行。

最终验收还需四产品分别观察：命令写入和读回、保护阻断、通信丢失恢复、AFE 报告有效性，以及 Gate/Vgs 和真实负载通路。寄存器状态不能替代物理关断证据。
