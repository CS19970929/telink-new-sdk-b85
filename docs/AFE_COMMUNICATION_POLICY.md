## 2026-10-21 故障恢复与功能故障分离

实施起点为 `8d27553b`。以下是当前恢复策略，覆盖下文旧固定提交中无条件静默、清标志失败锁存的描述。

- 普通测量/开启事务失败仍按实际时间持续 1000ms 确认；明确关闭操作失败立即进入禁止输出路径。
- 只有已验证固定配置且没有配置禁止时，才尝试恢复前关断。DVC 使用两侧硬 OFF；SH 先关闭
  `MOS_EN` 再清 CHGMOS/DSGMOS，避免自主反向通路绕过普通 OFF。均衡同样必须确认关闭。
  成功仅说明命令/回读契约已满足，不是物理 Gate 或整板隔离测量。
- 关断验证失败或配置未知，继续完整 DVC 5s / SH 35s 总线静默。静默期间所有公开总线入口仍禁止访问。
- 关断已验证时，下一次超过 200ms 的调度可初始化，不强制等待硬件 WDT。长静默后的首次初始化失败，
  也允许短间隔重试；每轮最多三次，只在首轮恢复起点之后 4s 内安排短重试。次数/窗口用尽后重新完整静默。
  此窗口约束重试安排，初始化仍保留芯片既有有界等待，不宣称全部恢复必在四秒内完成。
- SH 在状态读取和初始化中优先处理 WDT，不依赖 VADC/CADC 或普通 FLAG1 清除成功。
  先撤销自主通路及旧 ON 控制，再针对 WDT 清除并回读，随后不发送RESET而完整重应用运行/保护配置并等待采样稳定，保留其它保护标志；不能直接重新开 MOS。
- 删除 SH 清标志失败后永久拒绝采样的 RAM 锁。普通 SC/OCD/OCC 等仍须新的物理恢复证据，失败保留相应保护；
  已完整取得的测量可继续给 SOC 使用，但失败周期不能新开 MOS。WDT 未完成恢复不伪造有效测量。
- 均衡读写失败仍禁止同轮新开；仅当随后确认均衡 OFF 且必要 MOS 操作成功时，不将功能故障升级为整颗 AFE 失联。
  OFF 未确认、必要控制失败仍走故障确认，不以局部成功清除此前的通信观察。
- 本轮不缩短硬件 WDT 周期、不改变保护阈值、真实故障锁存、200ms 正常采样、SOC 积分公式或 Flash/OTA 布局。

芯片依据：本机 DVC1124-2 RM V1.2 物理页 15/16/30/31 的 CHGC/DSGC 与驱动逻辑，DS V1.1 p19 的
IWTS/IWTF；SH36735XX CV1.0A 物理页 17 的 WDT、MOS_EN、9.8s Powerdown 条件及 p26 的复位。
原件型号/版本与实装适用性缺口沿用 [AFE 资料指南](AFE_REFERENCE_GUIDE.md)。短重试不能恢复真正持续失联的硬件，
也不能通过 SPI 唤醒已经进入 Powerdown 的 SH。实板必须验证 Gate、WDT 计时、关断/清除次序及持续故障路径。

D014 的 485 供电保持另设 10s，不改变这里的 1s 通信确认；见 [架构中的通信所有权](ARCHITECTURE.md#6-通信与采样所有权)。

## 用户确定的策略

- 删除采样活性监测，包括 ADC 年龄、停更故障、公共新样本配对和三次新样本输出资格。
- 正常约 200 ms 完整读取测量和状态；CRC、长度、换算、有效通道和传感器合法性仍须检查。
- 偶发通信失败不触发 AFE1，不因通信失败撤销既有功率 MOS 资格。测量读失败的数据不发布、不积分，不作为保护恢复证据；完整测量后的控制失败另行记录，不伪造测量无效。
- 持续通信异常按 1000 ms 确认；一秒是软件确认时间，总线失效时实际关断仍依赖后端原有 watchdog。
- 已确认的配置不一致、明确芯片故障、真实保护及用户关闭继续生效。
- 用户接受不独立诊断“通信成功但 ADC 内部停止更新”；不以别名或业务门禁重新加入此检测。

根协作规则已同步此决定；旧文档中的 ADC 活性、两秒停更及三次新样本资格要求失效。
旧固定提交的测试收据仍只证明当时实现，不能作为本策略的验收结果。

## 所有权和数据流

`app_sample_task()` → `bms_afe_sample()` → 选定后端完整读取/保护 →
`bms_features_service()` → `bms_afe_apply_outputs()` → SOC。

采样直接返回 `OK / NOT_READY / READ_ERROR / ERROR`，删除仅用于携带 `confirm_sample` 的结构体。
后端拥有寄存器、测量有效性、芯片配置和具体保护恢复；guard 独占通信确认、AFE1、输出授权与静默窗口。
配置事务继续独占配置一致性门禁，普通通信成功不能解除配置禁止。

完整读取成功后直接发布电压、电流、温度；没有 ADC 完成事件不使数据失效。
快照时间表示 MCU 接受该轮完整测量的时间，不是芯片内部精确转换时刻。
测量读取失败保留最后报告值，但 getter 返回无效；MOS 回读未知不能上报为已确认关闭。
测量已经完整而清锁存/控制/均衡事务失败时，后端测量有效性保持，公共 getter 仍受通信/静默门禁约束；guard 的 cycle_failed 禁止同轮新开。
必要业务失败与测量无效是不同事实，不能只从 READ_ERROR 推断电流为零或 SOC 必须作废本轮。

启动、重配和唤醒保留芯片所需初始化及稳定等待。完成配置验证、取得完整有效测量并执行保护后，
不再等待三次新转换。SH 温度启动等待、DVC 零点校准及传感器合法性过滤不属于活性监测。

## 保留的具体证据

- DVC 启动零点等待新的 CC2 完成，等待有界；CC2F 不跨失败事务缓存。
- SC/OCD/OCC 仍要求各自负载移除、充电器移除或可靠反向电流证据，以及锁存清除/回读。
- 电压保护恢复和相关检测模式继续使用所需转换完成证据；证据缺失只暂停该保护的恢复，不触发 AFE1。
- 均衡可信度和加热故障确认按完整有效业务轮次推进，保持原阈值和配置时间单位；调用者每个 200 ms 任务至多调用一次，不补跑历史轮次。
- NTC 无效立即阻断相应功能；DVC 的恢复滤波按完整有效读取推进，缺少 VADF 不撤销已合格探头。
- SOC 仍使用实际应用时间；测量无效区间不补算，控制失败不冒充测量丢失。调度、watchdog、保护滤波和物理恢复去抖继续使用自己的时间。

通信观察期只允许执行必要关闭，不凭失效快照重放 ON。
配置写入/回滚未验证以及明确芯片故障仍禁止输出；普通读错误不能伪装成配置故障。
