## 仍保留的关联和状态

| 项目 | 保留依据 |
|---|---|
| 200 ms 主任务、唤醒回调与 `s_sample_due` | ISR/低功耗回调只置位；主循环处理采样，PM 消费到期状态防止再次睡过期限。任务超时后立即保留待处理标志，不能只留周期轮询。 |
| AFE 有效缓存与新转换资格 | 应用观察周期不等于 ADC 转换周期。缓存可用于有效时间段积分，但不能增加 guard 三次样本或 feature 连续确认。 |

| 通信三次合格样本与均衡连续可信样本 | 前者恢复总线/输出资格，后者检查单体范围、跳变及压差；两者所有者和失败语义不同。 |
| 均衡 `balance_active`、实际位图与 `balance_off_pending` | 分别表示允许沿用停止迟滞的资格、硬件最后回读、关闭尚未确认。写入/回读失败时不等价，不能合成一个 bool。 |
| 均衡历史单体、充后会话、温度暂停 | 历史单体识别跳变；会话保留既有充后静置策略；温度暂停形成回差且 AFE 重初始化不能清除。 |
| Heater 命令、ARMING/ACTIVE、熔断锁存 | 命令与阶段并非总是相同：ARMING 等待充电路径阻断，异常可先关闭命令；不可逆熔断资格独立。 |
| SOC 上一有效电流、时间与积分余数 | 新输入快照在函数入口已更新；上一有效电流仍用于方向变化判定，重复时间/GAP 不能伪造连续区间；余数避免小电流累计丢失。 |
| SOC 电压、温度、故障、斜率和等待时间 | 仅取消业务活动阻断，未取消真实测量资格和电压校正条件；400 ms GAP 仍舍弃盲区。 |
| 软件保护、硬件保护、MOS 仲裁与 watchdog 静默 | 未修改其阈值、滤波、物理恢复和输出授权；取消 SOC 活动阻断不能改变 MOS 安全链。 |

未改变 AFE 寄存器、ADC 模式/周期、均衡硬件续期、GPIO、Flash/CFG2/OTA、协议地址或单位。器件边界沿用 DVC1124-2 DS V1.1 / RM V1.2、SH36735XX CV1.0A 及 [AFE 资料指南](AFE_REFERENCE_GUIDE.md)；本次没有新增寄存器或时序假设。
