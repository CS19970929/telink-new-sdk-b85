## 第一轮：失效轮次不重放旧远程关闭意图

guard 仲裁增加仅在本次调用有效的 `explicit_off_mask`，不增加跨轮缓存。
没有有效测量或本轮已有事务失败时，保留已开启的反向放行，不重新计算旧远程 OFF；
新用户关闭、产品撤销、参数/输出禁止和后端已确认保护仍可关闭指定方向。
完整有效轮次仍按最新方向重新执行远程关闭许可，协议响应时机不变。

补充 guard 的 CHG/DSG 对称场景：反向临时放行、读失败保持、新用户关闭另一侧、
完整读取后按最新方向重新仲裁。更新抽取签名与既有源码契约，不删除安全断言。
未改变通信 1000 ms 确认、watchdog 静默、配置门禁或产品参数。
