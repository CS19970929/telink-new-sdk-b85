# SH3673520 20S 协议与参数完善说明

日期: 2026-06-08

本文记录在硬件联调之前已经完成的软件侧完善项，覆盖 AFE 参数默认值、Modbus 地址扩展、AFE 参数状态字、上位机解析和测试契约。

## 1. AFE 参数镜像

SH3673520 参数窗口仍从 `0x2200` 开始。持久化参数为 `31` 个 word，新增只读状态 word 后，上位机默认读取 `32` 个 word。

| 地址 | 偏移 | 权限 | 含义 |
|---:|---:|---|---|
| `0x2200` | 0 | RO | 固定型号字 `0x3520` |
| `0x2201` | 1 | RO | 串数，当前为 20 |
| `0x2202` | 2 | RW | 采样电阻，单位 uOhm |
| `0x2203` | 3 | RO | 最近一次 `BSTATUS1:BSTATUS2` |
| `0x2204..0x2206` | 4..6 | RO | `FLAG1/FLAG2/FLAG3` |
| `0x2207` | 7 | RW | 预留固件参数 |
| `0x2208..0x221E` | 8..30 | RW | SH3673520 `0x41..0x57` 配置寄存器镜像 |
| `0x221F` | 31 | RO | 最近一次 AFE 参数应用/读写状态 |

新增状态 word 编码:

| bit | 名称 | 含义 |
|---:|---|---|
| 0 | `FLASH_FAIL` | 内部 Flash 参数保存失败 |
| 1 | `SPI_FAIL` | 写 AFE SPI 寄存器失败 |
| 2 | `INVALID_WRITE` | 尝试写只读或越界 AFE 参数 |
| 3 | `READ_FAIL` | AFE 采样读寄存器失败 |
| 15..8 | context | 失败寄存器地址或参数偏移 |

`0x0000` 表示最近一次应用成功。写 `0x221F` 会被固件拒绝，并返回 Modbus 异常。

## 2. AFE 默认值

旧实现只设置了 `SCONF4` 和 `SCONF6`，其余镜像为 `0`，在应用参数时会覆盖芯片复位默认值。现在默认参数按文档补齐:

| 寄存器 | 地址 | 默认值 | 说明 |
|---|---:|---:|---|
| `SCONF2` | `0x41` | `0x50` | 芯片复位默认 |
| `SCONF3` | `0x42` | `0x00` | 芯片复位默认 |
| `SCONF4` | `0x43` | `(0x03 << 5) | 20` | 保留 PDSGT 默认并设置 20 串 |
| `SCONF5` | `0x44` | `0x38` | MOS/OCC/CADC 使能默认 |
| `SCONF6` | `0x45` | `0x3F` | 板级默认: TS1/TS2 + SC/OCD/UV/OV |
| `SCONF7` | `0x46` | `0x04` | 芯片复位默认 |
| `OWV/ALARMH` | `0x47` | `0x57` | 芯片复位默认 |
| `ALARML` | `0x48` | `0xFF` | 芯片复位默认 |
| `OVT/OVH` + `OVL` | `0x49..0x4A` | `0x33, 0x48` | OV 默认 4.200V |
| `UVT/UVH` + `UVL` | `0x4B..0x4C` | `0x22, 0x1C` | UV 默认 2.700V |
| `OCD1/OCD2/SC/OCC` | `0x4D..0x50` | `0x39,0x39,0x07,0x6F` | 芯片复位默认 |
| `OTC/OTD/UTC/UTD` | `0x51..0x54` | `0x96,0x76,0x76,0x9E` | 芯片复位默认 |
| `BALANCEH/M/L` | `0x55..0x57` | `0x00` | 默认关闭均衡 |

如果内部 Flash 中已经存在旧版“空白配置镜像”，启动加载时会自动识别并恢复上述默认配置，然后重新保存。

## 3. Modbus 实时窗口 v2

实时窗口从 `0xD120` 开始，版本升级为 `0x0002`，长度从 `11` 个 word 扩展为 `17` 个 word。前 11 个 word 保持兼容，后 6 个 word 提供精确单位和状态。

| 地址 | 含义 | 单位/编码 |
|---:|---|---|
| `0xD120` | magic | `0x4253` |
| `0xD121` | version | `0x0002` |
| `0xD122` | 兼容总压 | 16 位饱和值 |
| `0xD123` | 兼容电流 | 有符号 0.1A |
| `0xD124..0xD12A` | SOC、温度、最高/最低单体、压差 | 旧布局兼容 |
| `0xD12B` | 32 位总压高 word | mV |
| `0xD12C` | 32 位总压低 word | mV |
| `0xD12D` | 电流单位 | 当前固定 `1`，表示 mA |
| `0xD12E` | AFE 应用状态 | 同 `0x221F` |
| `0xD12F` | 32 位有符号电流高 word | mA，充电为正，放电为负 |
| `0xD130` | 32 位有符号电流低 word | mA |

## 4. 上位机行为

- 默认读取实时窗口 `17` 个 word。
- 默认读取 AFE 参数 `32` 个 word。
- 调试窗口的 AFE 参数块会显示字段名、访问权限、AFE 寄存器地址和 bit 摘要。
- 电池状态页优先使用 v2 的 32 位总压和 32 位 mA 电流。
- 电池状态页新增 `AFE Apply Status` 显示最近一次 AFE 参数应用结果。
- AFE 写入仍限制在持久化参数 `0..30`，上位机不会主动写 `31` 状态 word。

## 5. SIF/BLE 业务上报

`sif_send.c` 的公开包和实时私有包仍按原协议输出 10mV 单位电压，但现在优先使用 `g_stCellInfoReport.u32VCellTotalMv` 换算，避免 20 串总压超过 16 位 mV 后被 `u16VCellTotle` 饱和影响。
